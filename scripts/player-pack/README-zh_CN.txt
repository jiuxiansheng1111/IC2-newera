IC2：新纪元 1.20.1 — 玩家测试包 r43

状态说明
r43 面向 Minecraft 1.20.1 / Forge 47.4.28 / Java 17。已完成构建、静态验包及开发机独立1.20.1实例安装；尚未启动游戏验收r43。不要把旧r40/r41的实测视为r43通过。包文件名：IC2-New-Era-1.20.1-Forge-47.4.28-r43.mrpack。

导入与启动
将 .mrpack 拖入支持Modrinth整合包的PCL2，导入为独立实例。旧版PCL2拖入无反应时，使用整合包安装入口手动选取mrpack。包内提供便携Java17及对应源码；15个依赖从锁定作者地址联网下载。若未自动识别Java，可选择实例内IC2-NewEra-runtime/java17/bin/javaw.exe。本包供新的1.20.1世界使用，不迁移1.19.2旧世界。

本包包含的宠物内容
- 加入 Create 6.0.8、Create: Meowchanics（机械动力：老吴学）2.3.1、Create: Biotech 1.3.0，并使用 Ad Astra 1.15.21。整合包包含新纪元本体与15个第三方运行时模组，依赖关系以最终mrpack清单为准。
- 机械猫狗采用四腿分开的方块模型；猫有尾焰与洁白羽翼，狗保留加长躯干。饥饿20点，每2分钟减1，归零后持续受伤可死亡。猫喂鱼、狗喂肉或普通猫饼；普通猫饼也可给主人驯服的狼回血，机械猫饼不可食用。猫狗打闹为非致死互动。
- 机械狗按钮可播放整段10分22.714秒用户提供音频；再次点击或动作中断可停止。该宠物音频随新纪元包提供，不依赖可选Voice-Bundle。
- 机械猫受铁砧或Create碾压机压扁后，主人持铲拾取猫饼，再将猫饼丢入真实鼓风机气流复原同一只猫；具体交互仍须在r43游戏内验收。

可选机器人AI语音
旧的 `IC2-NewEra-Voice-Bundle-Win64-2026.10.24.zip` 保持独立、原样保留，只用于原有机器人AI语音环境；安装、模型推理和语音效果没有因r43源码变化而获得新的实测结论。
1. 先导入普通mrpack并正常退出Minecraft。
2. 下载并完整解压外层Voice-Bundle ZIP；同目录中已包含 `Install.cmd` 和原样的内层Voice-Slim ZIP，无需另外下载工具或手动配对。
3. 运行 `Install.cmd`，选刚导入的1.20.1 / Forge 47.4.28版本目录（含相符的版本JSON），不要选mods、saves或共享.minecraft目录。工具面向新的独立实例；遇到已有自定义语音目录会拒绝覆盖。
4. 语音推理需兼容CUDA 12.8的NVIDIA显卡/驱动，建议至少16GB内存；完整解压需约11GB空间及临时空间，ZIP超过4GB需ZIP64支持。联机语音装在服务器主机，通过现有游戏连接发送，模型后端仅监听本机。
在机器人设置页选择中/日/英语音；声音生成、实际安装与新机器推理仍待验收。普通文字游玩不需要此附件，机器人AI语音默认关闭。宠物狗叫声是新纪元内独立音效，不需要安装Voice-Bundle。

范围与注意事项
Minecraft、账号、API密钥和存档不随包提供。自由LLM聊天需玩家自行设置服务。不要把第三方模组JAR或许可未核实的用户音频提交到公开源码仓库。第三方许可与来源见 THIRD-PARTY-NOTICES.txt；实测状态见 PLAYTEST-STATUS.txt。
