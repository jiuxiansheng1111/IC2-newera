IC2：新纪元 1.20.1 — 玩家测试包 r46

状态说明
r46 面向 Minecraft 1.20.1 / Forge 47.4.28 / Java 17。最终源码构建已成功，并完成静态资源核对；本轮没有进行游戏实机验收。2026-10-27已通过既有脚本更新本机独立1.20.1实例，保留旧JAR备份；本机可正常启动原独立实例，不必重新导入。可分享的游玩包文件名为 IC2-New-Era-1.20.1-Forge-47.4.28-r46.mrpack。源码同步以公开分支和项目交付记录为准。

导入与启动
将 .mrpack 拖入支持Modrinth整合包的PCL2，导入为独立实例。旧版PCL2拖入无反应时，使用整合包安装入口手动选取mrpack。包内提供便携Java17及对应源码；15个依赖从锁定作者地址联网下载。若未自动识别Java，可选择实例内IC2-NewEra-runtime/java17/bin/javaw.exe。本包供新的1.20.1世界使用，不迁移1.19.2旧世界。

r46 协作建造与图纸
在机器人工作页打开“建造与生产线”，选择1–8名，人数包含领队。同主人、同维度、64格内已加载的空闲机器人可参与。先给每台机器人准备电池、食物和材料，各自使用自己的货物槽，不会自动从队友背包取料。先预览，再点“开始施工”。共享进度持久保存；缺料、停电、通路受阻时等待补给，可暂停、继续或取消；取消保留已放建筑。
点击“文件图纸 / 图片”→“打开图纸目录”，放入.nbt、.schem v2/v3、.litematic、带内嵌贴图的cuboid .bbmodel、紧凑.json或PNG/JPG。固定目录为当前版本目录/IC2-NewEra-blueprints/inbox；附带example-house.json小屋示例与README.md。也可拖文件进窗口。
普通蓝图可直接解析；自由描述点“AI创作”，参考图片点“解析并预览”，需要启用玩家已有的AI配置，图片需要视觉模型。文字/图片会发送至已配置AI服务，图片和密钥不发给游戏服务器。AI结果按外观优先生成三维方块方案，内部可自行调整；无法保证单张图片准确还原不可见结构。生成JSON存generated，复制到inbox后可编辑重导入。
预览是实际方块位置与近似颜色的示意，阶梯/半砖细节以游戏实物为准。外观曲线由方块阶梯层次近似。每文件8 MiB、最多16384构件、最大97×65×97格，过大的状态数据会要求拆分。高处或封闭建筑需要玩家搭通路/脚手架；不会瞬移、凭空耗材或自动拆除障碍。详见图纸目录README。图片质量、多人走位与存档续建尚待实机验证。

本包内容
- Create6.0.8、老吴学2.3.1、Biotech1.3.0、Ad Astra1.15.21，保持15个锁定第三方依赖。
- 机械猫现在继承原版 Cat 实体并接入老吴学完整玩法：产气、27格共享物流、配饰及饰品词条效果、13种职业外观与能力、发射器、繁育、融合和分裂等；老吴学菜单增加机械猫入口。猫保留既有方块模型、面部、白羽翼与尾焰；狗保留既有外形和音频。上游功能在源码中接入，仍待目标实例实机验收。
- 猫狗40生命/100饱食，复用IC2普通re_battery合成及更换，保留输入电量。正常20TPS持续活动满电约3小时，满饱约4.5小时；静止30/45小时，暂停及未加载不耗。
- 右键物品与装备页安装普通箱子解锁27格货物；先清空再拆箱，货物随主人运输。机械猫的27格共享物流接入老吴学玩法。
- 皮革/铁/金/钻石马铠任选一件即可显示全套护甲；护甲可与货箱同时显示。
- 普通猫狗防卫基础伤害3；狗追击并咬击，猫按老吴学职业武器与属性执行原生职业攻击，未装备职业能力时挥爪。猫饼发射声音沿用已有音频行为。猫狗彼此仍非致死打闹，可开和平相处。
- 猫喂鱼、狗喂肉/普通猫饼；普通猫饼能驯服野狼、治疗或繁殖已驯服狼。机械猫饼不能喂食。铁砧/机械辊压扁、主人铲取、真实Create气流复原保留机械身份。新生儿不复制父母的电池或货物。
- 落地镜与梳妆镜显示附近玩家、机械猫狗及原版猫狼动态倒影；不是完整建筑反射。机械猫正面看见落地镜会靠近、弓背哈气。
- 人形100生命/200饱食，原电池系统保持；正常活动饱食9小时、静止36小时，为其电池续航1.5倍。主人持食物右键有专门连续进食动作。饱食0都会持续受伤并可死亡。
- 狗面板“大狗到底叫不叫”保留完整622.714秒用户音频，手动播放/停止并伴舞。此音效已随JAR内置，无需Voice-Bundle；狗攻击低吼，不替换为猫饼发射音。

可选机器人AI语音
旧的 `IC2-NewEra-Voice-Bundle-Win64-2026.10.24.zip` 保持独立、原样保留，只用于原有机器人AI语音环境；r46没有更换或重新打包语音bundle。
1. 先导入普通mrpack并正常退出Minecraft。
2. 下载并完整解压外层Voice-Bundle ZIP；同目录中已包含 `Install.cmd` 和原样的内层Voice-Slim ZIP，无需另外下载工具或手动配对。
3. 运行 `Install.cmd`，选刚导入的1.20.1 / Forge 47.4.28版本目录（含相符的版本JSON），不要选mods、saves或共享.minecraft目录。工具面向新的独立实例；遇到已有自定义语音目录会拒绝覆盖。
4. 语音推理需兼容CUDA 12.8的NVIDIA显卡/驱动，建议至少16GB内存；完整解压需约11GB空间及临时空间，ZIP超过4GB需ZIP64支持。联机语音装在服务器主机，通过现有游戏连接发送，模型后端仅监听本机。
在机器人设置页选择中/日/英语音；声音生成、实际安装与新机器推理仍待验收。普通文字游玩不需要此附件，机器人AI语音默认关闭。宠物狗叫声是新纪元内独立音效，不需要安装Voice-Bundle。
