## 构建

需要 Java 17、Python 3 和首次联网。保持此目录层级，在当前目录执行：

```powershell
python scripts/bootstrap-public-dependencies.py
.\gradlew.bat build -x test
```

引导程序只在相邻 `../verified-maven` 下载锁定作者构件并校验 SHA256；从已校验的 Create JAR 提取三个编译 API。不上传这些JAR，也不复制其他未使用的旧Maven缓存。其余依赖由Gradle从已有仓库解析。联网依赖未缓存时不能使用 `--offline`。

已有本地构件可以只核验、不联网：

```powershell
python scripts/bootstrap-public-dependencies.py --verify-only
```

r45完整本地源码的最终构建已成功，耗时33秒；没有新增或运行测试。公开删减树没有重新构建，不宣称与完整本地JAR相同。完整r45本地JAR已通过既有脚本安装到独立1.20.1实例，旧JAR保留备份；玩家包与公开源码同步状态见仓库交付记录。模型源及导出脚本位于仓库根目录 `art/mechanical-pets/voxel` 和 `scripts/export-mechanical-pet-mesh.py`。源码被刻意按清单追踪，其他 `build-isolated` 缓存继续忽略。
