# 远征装备联动

## 联合包的装备工位

齿轮盛宴联合包使用 TaCZ 1.2.0 与 Create Armorer。联合包沿用选定的 Create Armorer 型号：TaCZ 工位中“起重机”工坊装备的型号 ID 为 `create_armorer:rifle_assult_crane`，配方仍为 6 个 IC2 高级电路、3 个 Create 精密构件、2 个 IC2 碳板；AI AWP 的型号 ID 为 `tacz:ai_awp`，游戏配料仍为 8 个高级电路、4 个精密构件、3 个碳板。TaCZ 1.2.0 的枪械索引、工位配方格式和枪械物品 NBT 接口已逐项核对；两种装备与原有任务和工艺保持一致。

游戏的 Create 装配线也能产出这两种型号。FTB 验收读取物品内的型号信息。其他外观相同的物品不能代替。

## 生态相册和半小时委托

工业手机和 Exposure 相机都能记录实际拍到的目标。在原有鮟鱇鱼、蛤蜊、金枪鱼之外，联合包支持浣熊、海豹、走鹃、三叶虾。首次留下这四种新目标之一的服务器确认记录，就能完成“齿轮盛宴的野外来客”；公开发布是另一个操作。手机相册与导航可使用已记录的观察点。

公告栏按玩家进度提供个人委托，半小时换一批，接单后拍摄才算本次委托。采集委托会消耗清单中的物品；多做一套备品再交。匠魂、矿物、洞穴战利品的固定发展线在 FTB 任务书，直接查任务名称可以看到交货数量、前置和个人奖励。

## 固定旋翼机

远征旋翼机使用 `immersive_aircraft:gyrodyne`，中文名“固定旋翼机”。Create 序列组装使用飞机船体、Create 精密构件和 IC2 高级电路，产出可驾驶的飞机物品。该路线与模组自带的双翼机配方并存，可将固定旋翼机作为工业远征目标。

## 月球和火星该走哪条线

新纪元手册的月球远征通过 Ad Astra 火箭前往 `ad_astra:moon`，手机按这个维度确认落月。齿轮盛宴原有的星际探索使用 Northstar 火箭与星图，对应的月面是 `northstar:moon`。两处月面和两处火星各有独立坐标；看路线卡上的模组名即可区分。去错月面可以记下观察点，落月任务仍要回到对应航线完成。
