# 当前玩法与电力问答（2026-10-23）

## 版本依据、用途与配方查询

本指南用于 Minecraft 1.20.1、IC2 Refactored 2.10.33-ex120、Create 6.0.8 与新纪元隔离迁移版；它不是 IC2 Classic 手册。设备 ID、实际槽位和迁移功能以目标依赖注册、目标版源码及当前界面为准。精确配方与数量读取当前 ProcessGraph 和 JEI。旧版 IC2 Classic 的设备名称、充电板等级、16格布局、I/C/S 面板说明和配方不能直接套用。目标版本没有核实的特例请查看当前 JEI/设备 GUI，不能根据旧教程猜测。没有本服配置或现场状态时，不宣称设备当前安全或已经修复。

## 机器人电池、充电宝等级与手机电量

新纪元 `ic2newera:robot_battery` 为等级3、容量4,000,000 EU；`ic2newera:industrial_phone` 为等级1、容量200,000 EU。移动充电宝分别为：`power_bank` 等级1/4,000,000 EU，`intermediate_power_bank` 等级2/8,000,000 EU，`advanced_power_bank` 等级3/16,000,000 EU，`nuclear_power_bank` 等级4/32,000,000 EU。等级、容量和传输上限是不同属性；普通移动充电宝用 IC2R 电池管理器传输 EU，兼容性受来源等级和目标物品管理器规则影响。

## IC2 Refactored 储电设备与充电槽

储电设备、充电格和放电格按目标版本各自的界面和原生电力等级工作。不要把物品等级、机器输入等级、储能容量和 EU/t 混成同一个数值；也不要把“储电箱”统称为一种槽位布局。针对某台设备，请查看其当前 GUI、鼠标悬停说明和 JEI；未逐项核实的储电箱兼容表、方向或红石例外不在本指南写成定论。

## 旧版充电台与电池站说明

本指南不沿用 IC2 Classic `charging_bench`、`battery_station` 的旧名称、16格布局或充电规则。目标版若询问对应设备，应先在当前 JEI 查真实注册名，再看该设备 GUI 的输入、输出和充电槽；未核实的旧版行为不视为目标版功能。

## IC2 Refactored 充电板：实际名称、扫描范围与电力参数

目标依赖中有四种原生充电板：`ic2:batbox_chargepad`、`ic2:cesu_chargepad`、`ic2:mfe_chargepad`、`ic2:mfsu_chargepad`。它们的机器等级、输出参数、储能容量依次为：BatBox（1、32 EU/t、40,000 EU）、CESU（2、128 EU/t、300,000 EU）、MFE（3、512 EU/t、4,000,000 EU）、MFSU（4、2,048 EU/t、40,000,000 EU）。这是板的电力参数，不是目标物品等级限制。原生充电板调用电池管理器时传入最高整数等级，因此能否充电仍取决于物品是否由管理器识别、是否有容量和板内是否有 EU。旧名 `chargepad_lv`、`chargepad_mv`、`chargepad_hv`、`chargepad_fission` 不对应这四个目标注册名。

充电板碰撞时记录玩家，服务器每两游戏刻尝试一次；每次找到第一个可充物品后就停止本轮扫描。扫描会查玩家主手、副手、四格护甲栏和完整36格普通物品栏（快捷栏与背包）。充电板界面只有待充电格和放电格，没有升级槽；不存在“宽频升级扩大扫描范围”的已核实实现。该方块处理的是玩家物品，不会因机器人站在板上就给机器人内置电池充电。机器人补电可在存活实体的九个货物格放置等级足够的充电宝，见下文。

## EU、EU/p、EU/t 与接线排查

EU 表示能量；EU/p 表示单个能量包大小；EU/t 表示单位游戏时间传输的能量。电力等级、线缆上限、变压器模式和机器输入条件要按目标版本实际设备说明核对。储能容量高或电量满本身不能说明下游可接受某个包大小；多台发电设备的总 EU/t 也不能替代输入耐压检查。接线前核对供电侧输出、线缆能力、机器当前输入和 GUI 提示，不凭旧版固定变压器面数、红石模式或包大小教程接线。

## 过压、线缆损坏与电力安全

目标版本的过压、线缆损坏和防护配置应以 IC2 Refactored 2.10.33-ex120 的实际机器/电缆说明及当前服务器配置为准。未读取配置时，不声称事故保护已打开或关闭；不把缓存容量、总 EU/t、单包过压和核反应堆热害混为一谈。出现停机或损坏时，先核对上游输出、线缆规格、输入设备和界面错误信息；不要照搬未核对的旧配置键或教程数值。

## IC2R 核反应堆与核能充电宝

IC2R 方块反应堆与新纪元便携核能充电宝是不同实现。方块反应堆的组件布置、冷却、产能和事故处理，请查看目标版本的游戏手册、实际界面与规划器；未核实的旧版周期数值和配置键不作为当前说明。

新纪元核能充电宝的燃料接受条件、热量、冷却、停机恢复、运行位置与输出细则统一见 `migration_runtime_zh.md`。本节不重复这些数值，以该迁移运行说明和物品提示为准。其他配方材料与数量查 ProcessGraph/JEI。

## 充电宝副手、玩家背包、机器人货物格自动充电

玩家副手持移动充电宝时，会依次尝试给手机、机器人电池和兼容的 IC2 电器充电；充电宝放主手或普通背包时，只给手机自动充电。充电宝来源等级不足时，IC2R 管理器不会接受等级更高的目标；初级和中级充电宝不能给等级3机器人电池充电。存活机器人的九个货物格中放高级或核能充电宝，可向已安装的机器人电池补电；需有机器人电池、充电宝有电且目标已加载运行。机器人已加载且待机时仍按游戏tick补电；死亡、收回为娃娃或离线时不补电，也不按现实时间追补。
## 机器人续航、工作、攻击、寿命和回收

机器人满电 400 万 EU。在正常 20 TPS、实体持续加载时，待命/普通跟随基础续航约 24 小时，工作模式/追击战斗约 6 小时；额外聊天、命令等仍扣各自费用，不能保证混合操作恰好满这些时长。未加载实体不会按现实时间继续运行。可装对应工具/装备执行有限范围伐木挖矿，默认防御敌对生物；杀戮开关额外攻击附近动物和怪物，始终保护玩家、已驯服宠物和机器人。派发指定采集会关闭广域杀戮，按实际数量收够后待命。每次死亡寿命扣 1，装入的电池清空；不到 5 次会按规则留下可回收娃娃，达到 5 次不再返还娃娃。正常“收回娃娃”不是死亡。查看角色信息、跟随、待命、回收和聊天均不再受成就门禁。

## 一张机器人图纸、八个娃娃、角色染料

robot_blueprint 是通用图纸，可用于八种对应娃娃的配方并在合成后保留。八角色为高松灯、千早爱音、要乐奈、长崎素世、椎名立希、八幡海铃、三角初华、丰川祥子。配方用各角色的染料区分，不是放下后随便加染料就变成任意角色。娃娃物品是棉花娃娃外观，放置后为可交互机器人。控制核心、执行器、电池与娃娃具体材料读取当前配方；不要推荐只用少量原版材料的旧简单配方。放置者所有，其他玩家不能因同一网络名就取得其机器人控制权。

## 手机联网、设备状态、远程命令与点歌

industrial_phone 是中后期电子材料加工机产物，配方由批准工艺给出。先充电，再进入有权限的工业 WiFi 网络，打开手机查看联网设备/自己的机器人。设备要已加载、在线并满足权限；有状态读取接口不代表支持远程启停。手机可发机器人命令和查看状态。点歌默认直接按歌名/歌手搜索网易云公开曲库，不需要 LLM，也不需要 JSON；智能点歌是单独入口。个人歌单可粘贴网易云公开歌单链接或 ID 导入，也兼容手工文本/JSON；导入会替换当前个人歌单。公开音源必须实际可用，付费/受限曲目、平台登录限制或缺少完整公开音源时不能保证播放，也不绕过平台权限。歌单和音频交付按玩家隔离，不把他人歌单说成本人的。点歌/机器人文字逻辑在 Mod Java 服务端，语音由游戏集成服务合成，不经过 QQ。

## 机器人讲话、AI回答、多人语音

角色文字回复和语音是不同环节。普通 AI 助手可在客户端开启朗读，收到完整最终回复后自动进入共享语音队列；也可朗读上一条回复、暂停/继续或停止语音。机器人角色语音使用同一客户端播放与排队能力。单人复用既有助手 LLM 设置，专服机器人聊天/点歌由服主配置专服模型，不将服主密钥发给玩家。长回复会切成小段依序合成播放；可用内存低于 1 GiB 时请求等待或排队，避免占用资源。关闭游戏时清理语音缓存。关闭朗读、排队等待、语音服务失败或客户端音量为零时不会听到声音，但完整文字回复仍可查看，不能据此声称已成功播放。离开聊天界面不会取消已经提交的语音。角色对话可引用同一份游戏知识，但聊天回复不会直接执行建造/修改设备操作；需要游戏已有操作按钮和权限校验。

## 电动工具、背包、护甲与拆机器

IC2 电钻、电锯、喷气背包、能量背包、护甲各有电量/模式和装备位置要求，名称相近不代表功能相同。查询具体物品时优先读取当前 IC2 手册对应条目，给出用途、充电方式、持握/装备位置和模式操作；未检索到绑定按键时引导看当前控制设置，不凭记忆编造固定按键。扳手、电动扳手、精密扳手、管道配置器用途不同；拆机器先看对应工具说明与当前模式，不能承诺任意镐拆除都会原样返还。容量、护甲保护和掉落概率未提供就不写死。

## 机器槽位、升级、自动输入输出与常见不工作

输入格、输出格、充电/放电槽、升级槽和方向配置依设备而异。请按目标版当前机器 GUI、悬停说明、实际手册与 JEI 核对允许物品、输入输出方向和升级兼容性。旧版 IC2 Classic 的 I/C/S 侧栏或其他旧设备操作不能作为本迁移版界面说明。物品放不进去时先看槽位允许列表、当前配方、物品等级和空间；设备停机时检查供电、缺料、产物堵塞和机器状态。没有对应目标版设备证据时，不推断过滤器、比较器、红石或升级行为。
## 手机远程角色聊天与语音

物品和页面名称为“手机”，注册ID仍为 ic2newera:industrial_phone。手持有电手机右键，联系人会自动列出自己放置的机器人；联系不限格数且支持跨维度，不要求双方在同一WiFi组件。机器人目标区块仍须已加载；未加载显示离线和最后位置，不会为了联系或采集强行加载区块。选中自己的在线机器人，点击“角色聊天 / 语音”即可远程联系。手机每次聊天消耗100EU，机器人沿用每次2000EU和聊天冷却；已准入请求不再额外预留一份电量，目标卸载/死亡/所有权变化会取消未完成文字请求。远程不能更换电池/装备或收回娃娃，这些仍须到身边操作。工业方块控制和手机音乐仍使用原有WiFi/光纤网络与权限。

语音开关开启时，角色回复使用该机器人的TTS/RVC音色并进入原全局队列，支持暂停/继续、重播上一条和停止。已获授权并排队的回复关闭页面后仍可播放；返回手机设备页切换角色不会把文字混进另一人的对话。同一次手机界面会话最多保留16个角色对话和草稿，退出该界面会话不承诺永久保存聊天记录。不同玩家的聊天、语音token和音频经各自游戏连接单播，是否多人实测须如实说明。真实手机App/安卓/iPhone远程联动不在该功能范围。

## 指定矿物或物品采集任务

也可以在手机的角色聊天或身边机器人的对话里直接说“帮我采集20个钨矿”“帮我捡3颗钻石”“请采集二十个钨矿”，无需打开物品选择页面。沿用原LLM识别本轮明确的物品、整数数量和自动/仅拾取模式，再由服务端按真实物品注册表、原文数量、所有权、在线状态和工具规则校验派发。一次只派一个物品目标，数量1～256，支持中文数词和一组64；名称重名、数量缺失或含糊、否定/假设/玩法咨询不会自动派任务，会提示补充。以服务端“已接收采集任务”回执为准，不能把角色随口答应当作已执行。聊天照常消耗机器人2000EU；成功派发另外200EU，手机这轮100EU已在聊天时付过，不重复扣手机费用。任务回执可沿用角色音色朗读。

手机联系人页、手机角色页和身边机器人页面都有“指定采集”。输入中文物品名或注册ID查找，选目标、填写1～256件并确认。可以自动定向采矿/伐木并拾取目标，也可只拾取现成物品。自动采矿须装备正确等级的镐，伐木用斧；仅操作任务开始位置附近、已加载且有可达空间的矿石/原木，沿用原版工具耐久/掉落和领地保护，不会挖穿任意方块或凭空造物。已加工粉末/锭等若附近没有现成掉落物，不会凭此任务绕过ProcessGraph生产。

一次成功任务或取消消耗机器人200EU，远程另扣手机100EU；同一任务重复提交不重置进度。进度只计算本任务实际进入货物格的目标物品，已有货物不计，足量停止，额外数量留在地面；堆叠和物品NBT保留。缺少工具/资源、目标不可达、背包不能容纳目标时显示等待原因。任务目标和进度随世界保存；收回再部署保留余量，但从新放置处重新确定本地工作区域。跟随、待命、普通采矿/伐木会取消指定任务。普通采集任务不会全地图搜矿或强制加载远方区块。

## Create 应力、转速、洗矿与工业流程

Create 的轴、齿轮和应力网络提供机械动力；提高转速会改变对应设备应力负担，过载一般表现为网络停止。转速方向冲突/超限是 Create 的机制，不能当成 IC2 单包过压爆炸。风扇吹过水形成可选清洗工序；含杂质粉也可按批准路线直接离心，但产量较低。金属合金配料走新纪元批准路线 `ic2newera:alloy_smelter`；不能用 Create 搅拌或工作台代替。新纪元初级/高级电动机将 EU 转为轴动力，初级/高级机械发电机消耗轴系应力产生 EU；工业 WiFi/光纤只传数据。实际发电、兼容与过压行为仍需游戏内验收。
