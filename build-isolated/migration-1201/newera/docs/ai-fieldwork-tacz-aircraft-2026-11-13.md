# 工业勘探装备与固定旋翼机

| 游戏工位 | 工业部件 | 产物 |
| --- | --- | --- |
| TaCZ 枪械工作台 | IC2 高级电路、碳板、Create 精密构件 | MK18、AI AWP，两种各有配方 |
| Create 序列组装 | IC2 高级电路、Create 精密构件 | 对应的两款 TaCZ 装备，保留各自物品数据，初始为空仓 |
| Create 序列组装 | 飞机机身、IC2 高级电路、Create 精密构件 | 沉浸式飞机的固定旋翼机 |

枪械工作台从实例根目录的 `tacz/ic2newera_fieldwork` 载入两条配方。Create 序列组装配方和飞机中文补充位于新纪元 JAR 内。领取上述游戏装备时，工业手册按实际物品与型号登记，「固定旋翼机」任务对应 `immersive_aircraft:gyrodyne`。

完整包包含 TaCZ 1.2.0 与 Immersive Aircraft 1.5.0。游戏内 AI 的中文资料位于 `data/ic2newera/ai/fieldwork_zh.md`，玩家可向它询问工位、材料、飞机名称与获取途径。
