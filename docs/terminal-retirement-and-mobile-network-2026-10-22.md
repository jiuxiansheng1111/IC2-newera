## 当前已经实现的网络

| 入口 | 当前实际能力 | 条件与边界 |
| --- | --- | --- |
| 手机 → 自己的机器人 | 聊天、语音、跟随/待命、采集、工作、建造与生产线 | 联系不限距离和维度；机器人须存活、已加载且有电，手机也须有电。不强制加载区块；换装备和收回仍需近身。 |
| 手机 → 工业设备 | 查看已发现机器状态；对支持接口的机器启停 | 玩家在有权限的交换机 WiFi 覆盖内；目标同网络组件且已加载；控制服务器有 AI 核心并启用控制，用户有配置权限。 |
| 交换机 | 编辑网络名，内置 WiFi，与其他交换机通过光纤组成网络 | 名称 1–32 个可见字符。同名本身不授权或凭空连通。默认 16 格半径；增幅器为水平 40×40 格、上下各 16 格。 |
| 机器网络适配器 | 自动识别邻近机器并连接最近有权限的交换机，显示状态 | 默认无需配置。光纤可跨出本地 WiFi 范围；发现只覆盖已加载区块且有数量上限。 |
| 工业控制服务器 | 设备列表、运行/故障状态、批准工艺规划、控制权限 | 房主/服主与委托权限、全部玩家、仅房主/服主三档。AI 工厂问答为状态分析，不执行模型生成的控制提案。 |

当前实现 `ControllableMachine` 的设备为非金属处理机、电子材料加工机与 EU 电动机。其他 IC2/Create 设备可识别和查看已有支持的状态，不能将它们描述为全部支持手机直接启停。机器人操作原生 IC2/Create 生产线属于另一条实际搬运和施工执行链。

不要求填写 IP、子网、网关、DNS、端口或网络密码。模型 API 的地址和 Key 属于独立 AI 设置，本轮不读取或修改。

## 操作顺序

1. 给手机充电，右键打开。自己的在线机器人会进入联系人；选择“工作 / 管理”可以进入建造与生产线。
2. 要管理工厂设备，放置交换机并设置网络名，在机器旁放适配器；跨区交换机用工业光纤连接。
3. 放置控制服务器、装入 AI 核心并由有权限的玩家开启控制。手机在该网络 WiFi 下显示设备，支持控制接口的机器才有可用启停按钮。
4. 权限由设备所有权、当前队伍和服务器管理设置共同决定；更名不会授予别人控制权。
