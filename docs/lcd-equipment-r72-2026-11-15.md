# r72 工业手机应用桌面与液晶公告栏

## 手机

手持有电的工业手机，朝空处右键打开应用桌面。顶栏读取实际网络和手持手机的电量，时钟显示世界时间。底部横条可以用鼠标收起手机。

| 应用 | 点击后可以做什么 |
| --- | --- |
| 机器人控制 | 选择自己的机器人，进入聊天、工作管理，或带选中的机器人打开远征手记。 |
| 工业控制 | 查看工业 Wi-Fi 网络里的设备，按权限启停机器、调整电动机转速、管理交换机。 |
| 导航 | 查看当前路线、分步指引、缩放或停止导航。 |
| 远征手记 | 管理月球备货、小队、生态记录和多站行程。 |
| 音乐 | 进入游戏歌单和音乐播放界面。 |
| 虫洞 | 查看绑定的目标和传送条件。 |
| 相机 | 进入游戏取景，用当前按键切换视角和拍摄。按 Esc 或退出取景键返回桌面，退出取景默认绑定退格键。 |
| 图库 | 查看本机和服务器上的照片，选择拍摄位置或被摄位置导航。 |

两项控制应用各自显示设备和提醒，右上角可以点击「返回桌面」。本人权限、照片授权和命令的服务端检查仍由现有功能处理。助手的操作资料已按实际入口更新。

## 设备外形

公告栏使用 16∶9 液晶面板、压铸外壳、转轴支架和低压接线端。屏幕由实际付费运行状态驱动，接通后亮起，耗尽后显示暗玻璃。一级供电，每 12 个游戏刻消耗 1 EU。黑色盖板与液晶背光用了两种表面亮度。硬件造型参考工业平板显示器的结构。[研华 FPM-215W](https://emt-iiot.advantech.com/products/FPM-215W/mod/D9F30850-80DD-4185-87A5-CA6FD4DDFE3A)

手机采用金属侧框、独立侧键、底部充电口和双摄。机身比例参考 6.1 英寸 IPS 手机，外壳、界面及应用图标由项目自行绘制。[Apple 的 LCD 手机尺寸与屏幕规格](https://support.apple.com/zh-cn/111865)

## 使用与兼容

新手机是空电的。把它放进 IC2 充电设备，或者带着手机站上已经供电的 IC2 充电板。打开桌面至少需要 20 EU。右键朝空处打开应用；机身上印的图标不代替操作界面。

公告栏和虫洞储电设备现在累积电缆送来的小数 EU。过去，两台设备虽然向 IC2 报告还需电，却把每次送来的电量向下取整；只送入 0.5 EU 时始终不会收到电。现在两次半个 EU 可合成 1 EU。旧存档的整数电量照常读取，传送费用、供电等级与公告栏耗电均不变。

Grove 和怪物娘化只随 Windows 客户端提供。兼容层为铁门保留原来的外形，让空锅和三个水位各自使用 Grove 对应的模型；关闭 Grove 后可以回到原版炼药锅。两根浅灰蜡烛使用 Grove 的原图，飞船机翼和氧化剂采用已有游戏资源。九张尺寸过小的模组贴图在客户端从玩家已安装的模组读取，在内存中按整像素放大，安装包不用复制作者的画作。纯白共用图也对齐了图集尺寸。

在普通 Forge 47.4.28 的专用单人验收档中，手持手机完整显示，八个应用可从桌面点选。带电手机进入相机后按 Esc 回到桌面。从图库选已有照片的「去拍摄点」，地图显示主世界 (69, 132, -43)，给出下一步向西 (80, 131, -43)。工业控制页和机器人控制页均可打开，未配对时显示空名单。本次没有以空名单作为成功下达远程命令的证据。

随后从人偶放置高松灯，游戏授予「永恒的伙伴」，手机联系人从 0 变为 1。伙伴位置、电量和剩余寿命都能在手机上看到。实际遇到的按钮提示问题是零电量被写成「没有控制权限」；服务端目前区分机器人缺电、当前离线和主人不符，并将同一原因回传到设备卡、聊天和工作页。断线不会删除尚未发出的提问。

在验收档给高松灯的专用槽装入有电的机器人电池（使用游戏命令准备条件），再在手机「工作」页真实点击「跟随主人」。手机收到「已下达命令：跟随」，伙伴从 (108,68,-37) 移到 (109,68,-38)。再次点击，手机回执为「待命」，状态为「待命 / 等待任务」，截图显示电量 196,788 EU、寿命 5/5。操作截图还暴露了工作按钮同时画出两个悬停提示的问题；工作页现在只显示一个原生提示，工作类型的提示仍随选择更新。

最终构件重新进档时，已配对的高松灯保持待命。在「跟随主人」按钮上实际悬停，F2 截图只有一个提示框；没有额外执行跟随指令。

临时取下这位伙伴的原电池后，联系人详情、电量为零的读数和禁用按钮的悬浮说明一致，实机显示「机器人没电；把充好电的机器人电池放进它的电池槽。」手机不再错报成权限不足。验收后恢复的是同一块原电池，并核查了槽位和余电。

在同一验收世界，玩家亲自放置一台工业网络交换机。手机「工业控制」发现 1 台在线设备，实际把它改名为 `R72-LCD`；设备位于 (112,68,-40)，改名后网络标题、设备详情和输入框均显示新名字。输入框的文字现已按服务端真实规则说明名字不能留空。这里实际验证了设备发现和远程改名，未把它算成所有工业机器的远程启停验收。
