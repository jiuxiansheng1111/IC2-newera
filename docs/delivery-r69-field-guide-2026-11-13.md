# r69 · 新纪元工业手册与野外作业

适用 Minecraft 1.20.1、Forge 47.4.28、IC2 Refactored 2.10.33-ex120 和 Create 6.0.8。

## 入服后的第一步

打开自动发到背包的《新纪元工业手册》。在「矿场起步」点勾报到，再点奖励图标，拿走自己的公告栏。组队玩家各领一份。背包满时可先整理再领取。死亡重生缺书会补发，玩家无需合成手册。进度界面使用 Create 安山机壳背景，手册用方形和齿轮节点连接前置任务；关键操作会弹出中文进度通知。

| 手册章节 | 玩家要完成的事 |
| --- | --- |
| 矿场起步 | 从采铅到打粉、可选水洗、热能离心和熔炼，逐步领取发电机、打粉机、热能离心机和电炉 |
| 合金与电子 | 建传动线和合金炉，制作低碳钢、PCB、集成电路与电动机 |
| 同伴与拍摄 | 完成第一份委托，装备工业手机，领取剩一次损坏机会的机器人、机械狗与机械猫 |
| 月球与火星 | 备好发射物资，登记真实着陆点，采集月球钒、钴、钼和火星铌、钽，取得共振碎晶 |
| 飞行与装备 | 建装备工位，取得装配线支持的一款勘探装备，装配固定旋翼机 |

章节取材、布局参考来自 Create: Above and Beyond 的 FTB Quests 工程。任务文字、依赖和奖励按本包实际玩法编写，用 AutoFTBQ 的生成器离线输出。模板通过 GitHub MCP 核对。游戏内的 AutoFTBQ MCP 需要运行游戏，本次采用离线生成。[Create 任务模板](https://github.com/simibubi/Above-and-Beyond/tree/main/config/ftbquests/quests) · [AutoFTBQ](https://github.com/Bluelgin/AutoFTBQ-v2) · [游戏内编辑工具](https://github.com/Bluelgin/AutoFTBQ-MCP)

## 公告栏

公告栏接 IC2 一级低压电。持续供电时每 12 游戏刻扣 1 EU，正常 20 TPS 下一分钟共耗 100 EU。右击屏幕即可查看个人委托，悬停可读完整要求和实物报酬。任务栏同时显示材料或目标生物图标以及奖励模型。

委托每 30 个现实分钟轮换。每人最多同时接五项，接下的任务跨轮保留，交货与领奖回原公告栏办理。累计完成 0、3、8、18、35、65、110、180 项时分别达到 E、D、C、B、A、S、SS、SSS。奖励随接单时的难度和任务类型确定，同一份已接工单的报酬固定。定向拍摄需在接单后拍到指定物种。

## 拍照、定位与登月

从工业手机打开「相机」。默认 V 循环第一人称、背后第三人称、正面自拍，P 保存本机原片，O 同时保存到本机和服务器，G 打开图库。Backspace 退出取景。Esc 打开原版暂停菜单并恢复原视角。本机原片在实例的 `screenshots/phone-camera/`，服务器原片在世界目录的 `ic2newera/phone-photos/`。服务器照片默认私有，可以从个人图库选择公开。服主能调整保存上限，默认每人保留最近 48 张且不超过 192 MiB，超额时先清理旧服务器照片。

在图库里选择去摄影者当时站的位置，或去目标生物被记录的位置，也可以把任一地点加入任务路线。导航使用照片所属存档记录的坐标。本机图库显示最近 96 张可预览照片，电脑保留原始文件。本机照片也能作为本服个人路标。公开生态相册支持生机遍布的鮟鱇鱼、蛤蜊和金枪鱼，胶片原片支持 Exposure。

「远征手记 → 任务路线」可编排最多 24 站，把当前坐标、照片、补给箱与已接委托排成行程。导航地图朝北，显示路线、下一格和高度变化，移动偏离时重新计算。跨维度时先去目标维度，前方区块加载后才续算；实体箱子等实心目标就近抵达可站立的位置。

月球远征可由小队共同管理备货箱、出发清单、落点和补给箱。起飞使用 Ad Astra 火箭和着陆器，落地后用手机确认位置。

## 工业装备和地图

TaCZ 1.2.0 提供两款枪械装备，工业配方使用游戏内的 IC2 与 Create 部件，可从 TaCZ 枪械工作台或 Create 序列组装线上取得。Immersive Aircraft 1.5.0 提供固定旋翼机。中文条目、配方与工业手机 AI 说明均随包分发。[TaCZ](https://modrinth.com/mod/timeless-and-classics-zero/version/QGCbNkTy) · [Immersive Aircraft](https://modrinth.com/mod/immersive-aircraft/version/aDUlOdzA)

另有现成的 Create: Custom TACZ Automation。作者列明其依赖 Create: Arms Race，共提供 576 条配方。本版的三条 Create 装配配方直接使用现有 IC2 工业部件，保留整合包原有生产线。[该附属的依赖与配方表](https://www.curseforge.com/minecraft/mc-mods/create-custom-tacz-automation)

服务端发行包从空目录部署时默认生成原版主世界，保留生机遍布。现有已生成区块不会因为更新自动改变。Windows 包保留客户端 Grove 与怪物外观。联机双方都需安装相同版本的新纪元和新增依赖；任务配置与 TaCZ 外置配方均在整包内。

本次按玩家要求未启动游戏。两人实服领取、相机原片显示、机器实际耗电和飞机起降仍待游戏内验收。当前在线面板使用另一套整合包，本次服务端文件用于新纪元服。
