# 1.20.1 第17轮：原生炒锅与改产检查

2026-10-23。这是源码、构建及资源静态核对记录，尚未安装、启动游戏或上传GitHub。旧1.19.2实例及存档未改。

## 本轮实际改动

- 新增森罗1.6.0炒锅适配器，接入原有烹饪派单、导航、取消和烹饪动作。按真实Pot优先、Flex其次的配方选择，用主人身份的FakePlayer及保护检查操作原生锅；食用油、各食材、厨铲及餐具均从真实货物转入持久暂存。
- 原生上油、逐槽投料、翻炒计数、工具损耗、取餐后清空状态分别核对。首次翻炒包含启动配方；公开序列化的原生剩余次数与任务已完成次数共同校验。灵活菜品保留实际品质NBT，不从静态输出生成结果。
- 区分待取餐和已取出暂存；满仓保留实物、清出空间后继续交付，不再次取餐。只有整批真实入库才更新订单。取消只退实际持有物，锅内不动；即使原锅移除，也可取消未含模糊操作记录的持有物。操作结果无法核实时保留记录并暂停，不自动补偿。
- 改产安全边界现在按旧计划的真实位置检查保留设备，包含Create置物台持物槽和8个加工输出缓冲槽，并核对真实方块ID。旧路线留下的材料不能被第二次改产忽略。
- 内置AI的两个实际加载文档同步炒锅和改产边界；核能移动电源提示改为“热管理与便携发电适配未完成”，不再笼统声称原生燃料接口不存在。详细核能接口证据见[审计](migration-1201-nuclear-bank-audit.md)。
