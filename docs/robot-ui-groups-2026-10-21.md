# 2026-10-21 机器人功能分组

用户反馈机器人按钮过多、功能分散。本轮保留已有功能，将近身机器人和手机机器人面板统一为四个分组。默认聊天页仅显示四个页签、关闭/返回和发送按钮，共 6 个；近身旧页面同时显示约 19 个按钮。

| 分组 | 功能 |
| --- | --- |
| 聊天 | 聊天记录、输入、发送；请求进行时同一按钮改为“取消请求” |
| 工作 | 跟随/待命切换、停止工作、指定采集、战斗开关、伐木、采矿、烹饪、重置烹饪 |
| 语音 | 朗读开关、暂停/继续、重播上一条、停止本机语音队列 |
| 设置 | 近身电池与装备、模型设置、清空对话、近身收回娃娃；手机端不开放远程换装备或收回 |

手机设备列表中原先重复展开的机器人指令，合并为“聊天 / 语音”“工作 / 管理”两个入口。指定采集与详细工作指令从统一面板进入；其他工业设备、网络名和音乐入口保留。

## 状态与交互

- `RobotControlTabs` 为两个面板共用导航及操作布局；切换分组只改变控件可见性，不切换 `Screen`，不取消异步聊天或语音。保留输入草稿、光标、消息和滚动位置，窗口缩放时保留当前分组。
- 生命、电量、寿命与工作状态持续可见；网络完整信息和每个操作的用途可悬停查看。按原版最低正常 GUI 320×240 排布：四个导航一行，工作操作两列四行，不再挤占聊天区。
- 隐藏的输入框失去输入焦点，避免在其他分组按回车意外发送；发送/取消的活跃状态随请求更新。真正离开近身面板时取消文字请求并恢复未完成问题，避免返回后残留未完成请求状态。
- 所有动作继续使用原有数据包、服务端权限/距离/电量检查和现有任务实现；机器人协议仍为 6。未修改工作算法、战斗、烹饪、模型、音乐/语音服务、存档或个人配置。
