# 服务器联网设备与运行诊断 AI 交付记录 · 2026-10-08

本阶段落实玩家要求：服务器界面精简、设备数/运行情况/故障、仅统计网卡或光纤接入设备、从名单选择控制，AI依据这些状态回答。

## 源码与使用

- 服务器300×226布局保留背包、独立AI核心槽和三档权限开关；“概览/联网设备”两页。概览只列网络、已发现设备总数、机器/终端数、运行/异常、可控制/未知和控制开关；机器列表每页3台，不需要输入坐标。
- 连续在线且实体不变的设备在同次服务器运行中保留编号和不透明UUID；断开、重放或服务器重新加载可重新编号。操作复查当前配置权限、距离服务器8格、核心/控制开启、同网、区块加载及BE身份，远端机器无需玩家靠近。
- 名单发现上限：32交换机、256光纤段、128网卡，每次索引256候选，终端计数32；统计标为“已发现”，不是无限全厂扫描。WiFi使用网卡，光纤直接相邻的原生机器可直连，网络基础设施不当作加工机器。设备和AI读取同一个名单。
- 读取IC2公开活动/储能/进度、Create转速/应力过载、新纪元受控接口。运行、待机、手动暂停、未知与异常区分；只有确有信号的缺电/供电不足/缺料/输出满/过载/错误计为异常。未提供具体原因的第三方机器只读并显示未知。Create运行表示动力轴转动，不能当作正在加工产物。
- 自动控制每20游戏tick刷新，控制改变暂停状态后重新采样。只读界面/AI刷新仅采集状态，不触发控制。
- 所有人可从服务器打开AI，沿用各自本机模型设置。每轮传运行/异常等汇总及最多16台设备（异常优先），带编号、位置、连接、运行/问题、储能/转速等有界详情。响应提示根据快照给建议，未知或截断不能声称已排查全厂；不能声称已经修复。
- 只读玩家没有执行票据。可配置玩家的终端提案仍须审阅确认并经过当前权限/网络/实体身份/版本/时效校验；终端库存另按自身ACL过滤。没有模型API仍可查看本地状态。
- 操作包协议升级为4；客户端和服务端须同时更新同一版本。
