# 机器人工作动作指导词与校准记录（r68）

## 可复用动作提示词

> 请为八个人形机器人设计短促、可读、克制的工作动作。只旋转现有 R20/R16 骨骼，不改模型几何、贴图、表情来源或比例。以服务器同步的 ToolStroke 进度为唯一动作时钟；接触峰值严格落在 `contactTick / duration`，不要按客户端随机相位猜接触时刻。每个动作按“低头找落点 → 提前预备 → 接触瞬间速度归零 → 很短的缓冲/回弹 → 放松回到原基姿”组织。关键帧间用平滑缓入缓出；动作开头和末尾精确回到该机器人的实时基姿，保留手持、呼吸和头部注视，不留腕部偏航残值。
>
> 五类动作必须有不同运动语言：锤击以肩肘带动清楚的挥弧、接触时停住、受力后小幅回弹；剪钳整体作为刚性工具朝向工件，辅手扶稳，禁止假造钳口张合；砂纸沿台面做有限次、短幅、真实接触的往返，反向点和接触峰值均要减速到零；刀具先对准切线，再向下切入，刀尖触板时停住；炒锅动作沿锅缘走椭圆，锅铲只绕腕部转向，不添加铲片开合动画。手工具必须跟随实际左右手和骨骼腕部，不能漂浮在脸前。
>
> 非工具手放在工具侧外缘或稳住工件，肩部、躯干和腿部只做小幅反向重心转移；不要全身僵直、节拍抖动或高频摆动。走路、战斗、受伤、吃东西、游泳、坐下等状态优先级更高，工作动作不得叠加或夺用它们的手。高低工件面用服务器提供的台面相对高度做有限下探修正。八个角色共享动作节拍，但不能改变各自网格、脸、头发、装备或正确骨骼枢轴。

## 本轮曲线与服务器节拍

关键数组保存在迁移版 `RobotAnimationPose.java`，运行姿态和预览器均读取同一组 Java 关键值。数组列依次为：躯干前倾、头部向下、工具手俯仰、辅助手俯仰、工具手外旋、辅手外旋、躯干反向摆动。节点位置为：0 搜索、0.18 预备、服务器接触比例、接触后 0.10 的短缓冲、0.82 回落，1.0 回到基姿。

| 动作 | 服务器时长 | 接触 tick | 接触比例 | 运动区别 |
|---|---:|---:|---:|---|
| 锤击 | 16 | 8 | 0.50 | 预抬后大幅挥弧，峰值停顿后反弹 |
| 剪钳 | 18 | 9 | 0.50 | 小幅合向工件，两手共同保持刚性朝向 |
| 砂纸 | 20 | 10 | 0.50 | 台面短行程往返，反向点降速 |
| 切割 | 18 | 9 | 0.50 | 预对准后刀尖下切，接触瞬停 |
| 翻炒 | 18 | 9 | 0.50 | 沿锅缘走椭圆并控制腕部转向 |

接触节点从各 `ToolStroke` 实际 `contactTick()` / `duration()` 计算；目前五种都为 0.5。砂纸与翻锅附加曲线也在 0.5 处导数为零，避免名义接触帧仍高速滑过。所有姿态偏移用入场/退场权重叠到当前基姿；地面工件根据 `toolSurfaceHeight()` 调整上身和手臂的下探量。

## 持物与状态裁决

`RobotRuntimeModel` 将实体左右手来源、动作进度与台面高度传给姿态器。`HumanoidRobotHeldItemsLayer` 按 `toolStrokeLeft()` 只替换动作实际持物侧，再按当前工具纹理里的握点/作用点和刚性长度对准固定工件；另一手物品单独保留。工作动作进出以平滑权重回到原有持物、呼吸姿态。战斗、进食等状态与工具动作不叠加。

## 离线分镜说明

`preview/render_storyboard.py` 从迁移版 Java 源读取动作关键帧和服务器接触比例，以可编辑安装用 R20 `anon.mesh`、其角色贴图、实际骨骼 pivot 与最终持物变换生成离线图。近景为约 60° 侧前视角、15° 俯角，画面保留头、手、台面及腰部；网格面按含俯角的相机深度从远到近绘制，并跳过透明纹理像素。工具纹理仅在本机依赖 JAR 内存读取，不另行导出或复制。

锤例使用铁锭→IC2 铁板；刀例使用生牛肉→农夫乐事肉馅。接触前显示原料，接触帧及之后显示产物；工件固定在服务器对应工作目标，不跟随工具尖端。桌面顶高分别采用普通台面 1.0 方块和砧板 1.125 方块，目标坐标分别为 `(0, 0.476, -0.57)` 与 `(0, 0.351, -0.57)`。预览读取当前台面补偿 `19/5/14/8`，与姿态 Java 源一致。

按 `HumanoidRobotHeldItemsLayer` 的最终握点、作用点和固定工具长度计算，锤的握点/作用点像素为 `(4.5,11.5)→(11.5,8.5)`、长度 `.47` 方块；刀为 `(4.5,11.5)→(12.5,3.5)`、长度 `.48` 方块。接触峰值时锤尖端到固定工件目标约 `.0068` 方块，刀尖约 `.0258` 方块。分镜也复刻持物层的刚性工具防穿面规则：接触外按 `surfaceY - (1-aim)*clearance` 限制尖端高度，保持腕部原点和工具长度不变，将水平分量投影到台面外侧；锤/刀 clearance 为 `.10` 方块。具体值见 `preview/contact-calibration.json`。这些是离线网格和工具纹理的几何校准，不是游戏截图或实机验收。预览展示锤和切两类最终实现；其余三类仍可从共享 Java 曲线生成总览，未声称已用真实工具纹理逐件核准。
