# r66 机器人共同回忆与工业炉外观

适用于 Minecraft 1.20.1、Forge 47.4.28、IC2 Refactored 2.10.33-ex120。r65 玩家关掉游戏，用 r66 新纪元 JAR 替换客户端实例 `mods/` 下的同名文件即可。机器人协议由 14 升至 15，工艺图协议仍为 36。

## 共同回忆怎么用

在自己的人形机器人或手机角色页打开「设置 → 共同回忆」，也可以直接问「你还记得我们第一次见面吗？」或「我们第一次做的菜是什么？」。每台机器人分别记录五件事，各记首次：新娃娃第一次与主人相遇、第一次成功摸头、第一次完成指定采集、第一次整单做好菜并放入货舱、第一次实际参与并完成建造。合作建造只算成功放过方块的机器人。旧机器人从更新后开始记，不补写以前的事。

联机记录保存在服务器主世界的 `data/ic2newera_robot_memory.dat`，随世界备份，单人游戏则随本地世界保存。收回后再放出仍继承同一台机器人的记忆；换电脑登录同一账号、同一服务器世界也能查看。服务器只记录事件的类型、时间、地点和结果，不保存聊天原文。只有主人能在游戏里读取，近身八格内可查；通过手机远程查询时，机器人必须已加载、有电，每次查询消耗手机 20 EU。回忆问答不调用外部模型。

## 设备外观

| 新纪元设备 | 原机外壳 | 新纪元的小标识 |
| --- | --- | --- |
| 合金炉 | IC2 电炉 | 铜色双锭 |
| 高级熔炼兼容炉 | IC2 感应炉 | 金色线圈 |
| 非金属处理机 | IC2 粉碎机 | 筛格 |
| 电子材料加工机 | IC2 压缩机 | 绿色芯片 |

四台新纪元设备的外形、色调、炉门和通风口沿用原机；正面只替换 5×3 像素，其余各面在游戏里引用 IC2 自己的材质。每台支持四个方向和待机、工作两种状态。真正用电推进工序才会点亮，断电和输出堵塞时恢复待机。已有世界里的设备可沿用，配方、存料和供电规则未改。
