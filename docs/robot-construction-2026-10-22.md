# 描述建房与机器人生产线

## 使用入口

近身角色或手机角色对话的“工作”页打开“建造与生产线”。输入描述，点“生成方案”，核对位置、占地、材料和工序，再点“开始施工”。方案保留10分钟；重新生成会替换自己上一个待确认方案。

聊天也支持明确指令，例如“建一间9x7的木屋，有玻璃窗和门”“搭建一条锡生产线”。这些短指令由服务端解析，即使聊天模型暂时不可用，也不依赖模型生成或执行任意游戏命令。收到方案后说“确认施工”；“暂停施工”“继续施工”“取消施工”“建造进度”分别暂停、恢复、取消和查看。生产阶段也支持“暂停生产线”“继续生产线”“取消生产线”“生产线状态”。

施工地点以生成方案时的机器人位置为基准，放在角色北侧，入口朝南。先让角色站在平整空地边缘。方案会显示起点坐标和维度；已有建筑、草丛、地形或未加载区块挡住规划位置时不能开始，不会自动拆除清场。仅检查目标格为空不等于已经具备承托地面和通路；机器人还会逐块验证支撑、寻路、视线与主人权限。

## 房屋描述范围

支持单层、长宽各5至13格、墙高3至4格，默认9×7、墙高3。尺寸可写“9x7”“9×7”或“长9宽7”。木屋、石屋、砖屋、白色现代混凝土四种方案可选，含玻璃窗、门、照明、工作台、箱子和熔炉；现代款另有灯笼。屋顶可选平顶或一格起伏的低斜顶。

“尖顶”目前对应预览中明确标注的低斜顶，不是任意高度的尖塔。多层、地下室、复杂房间、红石设施、未支持的木种/颜色等会说明不支持；不能把它当作任意建筑设计器。

将清单材料放入机器人的货物槽，可分批补充。每块按原生生存放置逻辑实际消耗，门只消耗一扇并由原版生成上下半部，水桶使用后返还空桶。启动花费200 EU，每次放置尝试20 EU，行走作业沿用角色日常耗电。缺材料、缺电、被保护拒绝或通路受阻时保留进度。

## 完整矿物生产线

此入口构建机器人搬运式场站。工序和产量读取当前 ProcessGraph 的批准路线，不使用网上替代配方，也不绕过杂质粉清洗。施工设备需要提前制作并放入角色货物槽；不凭空生成发电机、粉碎机或其他设备。

锡线路包含以下环节：

1. 原料入库：把方案指定的粗锡或锡矿石，以及煤炭/木炭放进进料箱。
2. 电力：IC2 发电机燃烧燃料，直接向相邻 IC2 粉碎机供 EU。
3. 粉碎：原生粉碎机把指定原料加工成含杂质锡粉，倍产数量由当前批准路线决定。
4. 搬运：机器人从实际输出槽取出杂质粉，走到 Create 置物台投入。
5. 水洗：真实水流驱动水车，轴向连接鼓风机，气流穿过水后处理置物台上的杂质粉，得到正常锡粉。
6. 熔炼：机器人提供净粉和煤炭/木炭，原版熔炉消耗燃料与加工时间产出锡锭。
7. 成品入库：机器人取出真实成品并送入成品箱，随后继续下一份原料。

EU和Create转速各自运行，不互相转换；机器人承担节点间的物品运输。线路包含底座、水流围挡、供电、机械动力、清洗介质、原料箱与成品箱，具体坐标及施工材料以游戏生成的方案为准。进料箱中的运行原料、燃料与施工材料分开列出。

默认持续生产，缺料后等待补充；明确要求“产出64个锡锭”时按完整原料批次规划，可能因为原矿倍产而略多于目标。生产需要角色保留三个空货物格作为本批原料、工序品和燃料暂存，不要手动替换这些正在使用的物品。实际设备槽位、配方、燃料、气流、保护事件与输出空间不满足条件时显示原因，不能把“机器摆好”当成“已经出锭”。

当前执行器仅支持批准的 IC2 粉碎机 → Create 水洗 → 原版熔炉/高炉这类单原料基本金属路线。钛、钨等要求高级炉的路线、合金多输入路线和不具备相应工序的材料会拒绝建设并说明缺失环节，不拿普通炉代替。原料开采可先使用已有指定采集功能；本场站从进料箱开始，不全地图挖矿，也不自动合成所有施工设备。

## 暂停与恢复

暂停、切换工作或战斗时保留任务与实物；恢复前重新校验所有者、维度、场地、批准路线与自有批次。正常实体保存会保存进度，本次开发不会直接读写玩家已有存档。

取消会解除机器人施工/生产任务，已放建筑和机器不会拆除，货物与机器内物料留在原处。原生发电机与炉体可能继续消耗已投入燃料和加工；暂停机器人不等于关闭机器。外部自动化或玩家改动已认领批次时，机器人停止接管，避免把别人的物品当成自己的产物。
