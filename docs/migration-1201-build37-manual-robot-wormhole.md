已部署与根目录12份第一方语音文件哈希一致，配置字段中实际工具/模型路径也一致；当前证据不支持把失败直接归因于旧服务没有更新。38的媒体限流修复只处理另一个可复现的快速回复问题，不保证解决内存不足。
