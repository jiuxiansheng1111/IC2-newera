# r73 手机导航与个人地点

在 Forge 47.4.28 的新纪元整合包里，拿着有电的工业手机，打开「导航」。地图朝北，黄点标自己，短线指示面向。地表采样取自客户端已经加载的区块。进入矿洞或多层建筑后，可以切到「分步路线」查看下一步的高度。

## 从基地走到矿点

1. 到达基地，打开「导航 → 地点」，输入「家」，点「保存当前位置」。
2. 到达矿点后，用相同方式保存「铅矿」。地点记录包含维度和脚下坐标，每个玩家在这个世界有 64 个名额。
3. 选中「家」并点「步行导航」。手机和 Xaero 的常规小地图显示同一条可行路线。手机上看绿色折线，小地图上看黄色折线。地表是俯视图，路线的每个节点还有自己的高度。
4. 两地相距很远时，服务器分段搜索，走近边缘后续算。缺少区块信息或地形堵死时，查看手机给出的状态。跨维度步行会提示先进入目标维度。
5. 需要直接返回时，选中地点并点「直接传送」。服务器从自己的记录读取地点，检查边界、地面、头顶空间、碰撞和危险方块，再将玩家送到安全位置。

个人地点存放在主世界的 `data/ic2newera_personal_places.dat`，依玩家 UUID 分开保存。更换手机仍能找到自己在这个世界保存的地点。服务器在存档的 `serverconfig/ic2newera-field-places-server.toml` 里管理 `teleportEnabled` 和 `teleportCooldownSeconds`，默认允许普通玩家使用，成功传送后冷却五秒。「更新所选位置」把该地点移至当前脚下，确认后生效。

## 小地图与船体兼容

Xaero Minimap 26.6.0 的地形和图标仍由 Xaero 绘制。新纪元在常规模式的小地图合成时使用同一相机、缩放及旋转，再由小地图的轮廓裁切路线。兼容模式用单独的像素缓冲叠线，停止导航后可以显示原始地形。Xaero 只安装在客户端。

Valkyrien Skies 2.4.11 在角色同维度复活时可能重复下发已在客户端加载的船。原处理器会先更新这艘船的运动状态，再抛异常，从而中断同批其他船的创建。客户端补丁检查船号和维度，用收到的运动状态更新原对象，继续处理批次里的新船。游戏日志第一次实际遇到重复记录会留一条确认。

在验收世界曾实际看到手机上的绿色地形路线，也复现了同维度船边死亡、复活。日志显示一条重复船同步记录已合并，船仍可见。此次复核还加强了小地图折线的对比度，并将甲板地点保存为船体相对坐标。船移动后用最新变换寻找安全落点。最终版黄色小地图折线及移动甲板传送尚无实机截图确认。
