# r72 单人世界兼容核查

本记录针对普通 PCL 的 Forge 47.4.28 独立包。测试使用单人验收世界；线上面板是另一套包，没有用这次文件覆盖它。

## EMC 与配方

价格按物品在游戏中实际可以兑换的 EMC 计算。原料的 EMC 为零时，不能把它当成凝聚器可免费复制的材料；需要向前查到可购买的材料。批量配方要乘以实际产出件数。第一次运行导出还揭示了由于前一级材料变便宜而产生的三叉戟、下界合金和纹饰模板路线。

| 对照 | 修复目标 |
| --- | --- |
| 木炭、糖、燧石 → 3 火药 | 材料 130，三个火药共 129。 |
| 末影之眼、4 海晶碎片、4 鹦鹉螺壳 → 海洋之心 | 按实际材料价值 1,520＋1,024＋4,096＝6,640。 |
| 海洋之心、鹦鹉螺壳、海晶碎片、2 海晶砂粒 → 三叉戟 | 6,640＋1,024＋256＋1,024＝8,944。 |
| 2 金锭、2 下界合金碎片 → 1 下界合金锭 | 按这条更省料的实际路线：2 × 2,016＋2 × 12,285＝28,602。 |
| 复制哨兵盔甲纹饰 | 新增一张的成本：7 × 8,064＋1＝56,449。原模板也在材料中，最终实际产出两张。 |
| 一级无尽工作台的灵魂沙 | 2 灵魂土、2 沙、1 石英产 2 灵魂沙，材料和产物均为 98 EMC；普通泥土缠魂产灵魂土，不再额外获利。 |
| 安山岩工作台 | 原来圆石 1 ＋闪长岩 16，合成 2 个安山岩共 32。与 ProjectE 同装时仍用这两份材料，产 1 个 16 EMC 的安山岩。挖掘和切石照旧。 |
| Create 安山合金 | 搅拌成本为 1 安山岩 16 ＋ 1 铁粒 28，比手工配方省一半。保留搅拌和手工的原产量，用较低成本定价：合金 44、压缩块 396。 |
| Create 水洗灵魂沙 | 原配方保留，石英 94，金粒 224，灵魂沙 49。每份平均产出 51.48，比投入高约 5.06%；单次结果是随机的。沙子缠魂变灵魂沙的路线按原设置保留。 |

对照按实际生效的配方进行。例如 Re-Avaritia 覆盖了原版的 5 号唱片合成：本包要 4 个唱片碎片（无尽贪婪，每个 1,024 EMC）和 1 个 16 EMC 的回响碎片，成本 4,112，高于唱片的 2,048。因此没有按另一个同名、未生效的配方去改唱片价格。ProjectE 映射日志仍可能打印虚拟材料标签的候选值；金锭、钻石及其制成的镐和胸甲均逐个核对游戏导出的实际物品价格。

最终普通 Forge 单人世界导出的物品价格共 2,506 个（SHA-256 `B3CBCFF3B6AB6F4CE27FE1D5FCF69AEB4CEC953AD3ACE4A96305FBAF76EBACEF`），47 个指定兑换值全部吻合。原版没有铜粒，最终实价表中只有 Create 和匠魂两个真实铜粒，两者均为 14。安山合金 44、合金块 396、传动杆 11、安山合金栏杆 11；安山岩切块仍为 16，半砖 8。将实际物价与当前 JAR 中无条件、原料可直接兑换、产量确定的普通合成、切石及无尽合成配方另行核对，共 2,243 条没有发现产出整批 EMC 高于可兑换原料的情况。此项不包含全部机器、带 NBT 的配方或概率加工；水洗是单独核算的保留例外。

世界实际启用了灵魂沙和安山岩两个修正包。在生存模式的背包 2×2 合成格放入一个圆石和一个闪长岩，手动取出一个安山岩，物品提示显示 16 EMC。灵魂沙工作台核对了生效配方和材料、产物的实价；水洗收益是按实际掉落概率计算的长期均值。

## 船体与客户端

原始 VS 模组对幽匿振动接口的注入不被本包 Forge 接受。发布时使用基于[上游的调用点修复思路](https://github.com/ValkyrienSkies/Valkyrien-Skies-2/pull/1982)的本地兼容构件；原 VS 与本地改版不能同时放在 mods 中。界面运行、资源、模型和手机导航见[实机记录](lcd-equipment-r72-2026-11-15.md)。

单人验收实际组装并固定了一艘船。右击船上的音符盒，音高从 F♯ 变成 G；地面感测器旁的投掷器把唯一的紫水晶碎片送入原先为空的接收箱。随后读取两个方块的库存，投掷器为空、箱中恰为一颗。这验证了船上发声、地面接收的方向；不能据此证明反方向也通过。

验收时先建成一艘物理船，再固定并移动它。角色在船边死亡、复活时，VS Core 另记录过一次重复收到已加载船只的创建包。游戏继续运行；正确修复需要协调服务端重发和客户端索引，不能简单忽略异常或清空正在使用的船只。遇到复活后船体位置异常，先正常退出并重新进入该世界或服务器。[上游相同症状](https://github.com/ValkyrienSkies/Valkyrien-Skies-2/issues/1699)

## 实际安装和发行文件

普通 PCL Forge 47.4.28 客户端有 46 个模组 JAR，服务端使用其中 35 个。Windows 与 Linux 共用一份服务端压缩包，客户端才带 Grove 等视觉资源。新纪元最终文件 SHA-256 为 `F8C5C659D6A14FBFE30D6A29285D5C1234D3F241092532AACA69D0A059F18D95`。实价和跟随/待命验收使用 `91ADC74D…`，随后换上 `0CFFFEE3…` 在同一存档核对单条悬停提示和零电状态。最终文件和后者逐个 JAR 成员及类指令核对，只有两处显示文案的字符串内容不同：网络名不可留空、手机与机器人各自需要供电。所有服务端代码、渲染逻辑、配方和网络协议均相同。ProjectE 的 118 项清单为 `5EC5828F5A6AC2A560E4F4661E5601A44D32A78869DE7A743D2A52F3B1557BCF`，含原来 71 项不可兑换的受控中间产物。新纪元随身助手同步了手机入口、机器人电池、灵魂沙水洗和工作台配方。
