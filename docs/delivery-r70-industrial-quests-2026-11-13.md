## 每周联合工单

1. 给公告栏接上 IC2 一级低压电，在左上角点「每周联合工单」。北京时间周一 00:00 轮换新工单。每半小时轮换的委托可在「日常任务」查看。
2. 查看每种材料的实物图标、已交数量、协作目标与整份报酬，选择要接的订单。两种材料或多个目标之间可以分次办理。
3. 回接单时的公告栏，点「交 1」或「交满」。服务器每次至多收下玩家身上现有的数量和本项剩余需求。按工单注明的条件完成日常委托或拍摄指定物种。
4. 所有条件完成后点「领取」。背包空间不足可以腾出位置再领。已签的单可跨周继续，每人最多同时保留六张未结订单；报酬按个人记录发放。

手机「任务路线」可以选择已接周单并加入交付公告栏的位置。分组、章节和周单都使用中文。工业手机 AI 收录了任务书导航、部门分工与每周交付的说明。

## 选择安装包

| 已有版本 | 使用文件 |
| --- | --- |
| r69 客户端或新纪元服 | `IC2-New-Era-r69-to-r70-Update.zip`，包含新纪元 JAR 和整套手册配置 |
| r68 客户端或新纪元服 | `IC2-New-Era-r68-to-r70-Update.zip`，含 r69 引入的依赖与配置，可一次更新到 r70 |
| 新玩家 | 在 PCL 导入 r70 Windows 完整包 |
| 新开服 | 使用 r70 完整服务器压缩包。已有存档先备份，更新数据和模组时沿用自己的世界目录 |

手动更新先退出游戏或正常停服，再把更新包的 `mods`、`config` 等目录合并到实例根目录。单独替换新纪元 JAR 不会带入新增手册章节。玩家的任务完成和领取状态在世界或玩家数据中，更新包只分发任务定义。
