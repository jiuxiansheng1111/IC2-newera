# IC2 Classic 机器界面答疑修正

目标版本：IC2 Classic 2.1.3.4 / Minecraft 1.19.2。

## 核对结论

截图中左上角 `I`、`C`、`S` 是三个独立按钮，不是一个“ICS”标识。根据 IC2 Classic JAR 中对应组件的按钮文字、悬停翻译键与简中资源：

- `I`：机器访问控制（Machine Access Control）。按 D/U/N/S/W/E 六面设置库存自动化访问。绿色勾选开关该面；`B` 按钮循环禁止、导入、导出、双向规则。选中槽位后还能改槽级规则；底部两项的中文悬停分别是“每个格子仅允许放入 1 个物品”和“每种物品最多只能放 1 组”。红色叉号表示限制关闭，点击切换，重置恢复默认。
- `C`：比较器设置（Comparator Settings）。设置机器红石状态输出的来源、最小/最大/平均评估及反转；能选的来源随具体机器而变。它不改变配方、库存或供电。
- `S`：格子过滤器信息（Slot Filter Info）。简中页的标题“有效格子输入”表示显示所选库存槽允许的物品；这是查询/识别槽位准入内容的界面，不是额外的物品格。

方向栏里的 `S` 表示 South/南方，和左上角 `S` 过滤器按钮不同。`D/U/N/S/W/E` 顺序是下、上、北、南、西、东。

Macerator 的 ID 为 `ic2:macerator`。背景和容器定义确认：闪电形区域是 EU 能量/充能指示，箭头是加工进度；右侧四格是 `SlotType.UPGRADES` 升级槽，显示名为“升级”。升级槽不是配方输入，留空可正常加工；只能放机器接受的升级组件。

## 给助手的简答

> 粉碎机左上角不是一个“ICS”标志，而是三个按钮：I 管机器各面的物品访问，C 管红石比较器信号，S 打开“有效格子输入”列表，查看选中的槽能放哪些物品。I 面板里的 D/U/N/S/W/E 才是方向，S 在那里表示南。左下两个红叉目前表示“每格一个物品”和“每种物品一组”的限制关闭；右边四格是可选升级槽；闪电是能量，箭头是进度。
