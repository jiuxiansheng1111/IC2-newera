# r71 齿轮盛宴与新纪元联合任务书

玩家提供的 Create-Delight-Remake 导入包作为底包，与 r70 的 IC2、新纪元、匠魂和其他现有模组合并。客户端使用独立 PCL 实例 `Create-Delight-New-Era-r71`。服务端交付为可在新目录解压的专用包，使用 Minecraft 1.20.1、Forge 47.4.28 和 Java 17。

## 玩家任务

手册沿用底包 2,509 项任务、32 个奖励表和新纪元 47 项原有任务。在 10 个新章节中加入 120 项固定任务，共 61 章、2,676 项。新奖励每位队员可各领一份。消耗任务在界面中按指定数量交货，设备登记类任务保留背包中的设备。

| 新章节 | 任务数 |
| --- | ---: |
| 野外观察 | 10 |
| 匠魂与工业委托 | 14 |
| 矿山化验室、动力车间与变电站、机械动力分拣线、ME 仓库和工业网络 | 每章 12 |
| 厨房与温室、生境巡护、传动与夹具、星间航路 | 每章 12 |

相册和公告栏可识别浣熊、海豹、走鹃和三叶虾，玩家用工业手机或 Exposure 相机拍到其中一种即可触发新的快门进度。公告栏扩充了定向拍摄、样本和耗材订单。Ad Astra 与 Northstar 的月球、火星坐标各自独立，手机路线标注航线名称。

## AI 助手

任务索引由最终 FTB 文件生成，客户端和服务端共用 `config/ic2newera/quest_knowledge.json`。助手可按任务名、物品名和注册 ID 找出交付扣除数量、设备检测条件、前置、下一步及奖励。原底包的奖励表保留随机、选择和整表奖励形式。原有工业操作和批准工艺查询仍走已有知识来源。

例如“给铅矿编批次”扣除 3 份粗铅，每人可领 2 根绝缘铜质导线，下一单是“留一袋含杂质铅粉”。这项检索已用发布 JAR、目标版本的 Gson 与本机安装的索引直接核对。

## 整合与验收

- 客户端 403 个顶层模组 JAR，服务端 345 个。两端共享 JAR 采用同一份字节。底包中的两份输入法修复合并为一份。客户端沿用底包 Colorwheel 渲染兼容，并默认关闭光影；Grove、CMM 与 iterationT 可在实例内使用。
- 底包的 TaCZ 附属依赖 1.1.8 的界面接口。联合包选用该版本，并将两条涉及底包缺失 MK18 型号的游戏配方、对应进度、任务说明和 AI 指引接到已安装的 Create Armorer 型号。
- 根据作者仓库补齐附件漏掉的 LDLib 机器资源。所选提交的 20 个 MBD2 服务端脚本与附件逐个吻合。两端均包含收购箱、温室建造器的注册定义，以及服务端物品交互需要的卫星导航界面。[对应上游提交](https://github.com/Jasons-impart/Create-Delight-Remake/tree/4ad7cde23c4bc266924f11a855b80784c6254a7e)
- 两端依赖、Forge/Maven 版本范围、嵌套库和重复注册 ID 静态检查通过。另有 110 条非阻断提示，包括模组软推荐版本不同与已解析的内嵌依赖。FTB 任务关系共核对 2,874 条前置、32 条章节链接，未发现悬空引用或循环依赖。
- 已构建新纪元发布 JAR，完成独立 PCL 客户端安装，并同步可分发的客户端和服务端包。

## 专用服务器实测

11 月 13 日上线后，Java 17 和 Forge 47.4.28 成功加载新世界。FTB Quests 在主线程读入 13 个章节组、61 章、2,676 个任务和 32 张奖励表。此后控制台多次响应玩家列表查询。公网 Minecraft 状态查询返回 1.20.1、协议 763、Forge 和 0/20 人在线。旧服已在切换前备份，旧地图另行归档。玩家进服、拍照、交货和领奖仍由玩家实测。

- 两端将 SuperMartijn642 核心库升级到 1.1.25a。该版本支持此处使用的 Forge 注册流程。
- 食物品质升级到 2.4.5，保留森罗厨房和食物品质流体联动。底包给旧版存档类使用的 `LevelData.badiff` 已移出，两端均使用新版模组的存档实现。
- FTB Quests 2001.4.22 使用 Java 的有符号长整数读取任务编号。生成器重新映射了 26 个超范围的新编号及其引用，保留其余 7,315 个编号。四个章节及助手索引已同步到服务器、本机和发行包。

启动日志里，ExtendedAE Plus 给 AE2 合成 CPU 菜单附加手动等待状态的功能仍有一条兼容警告。服务器在该警告之后完成启动并继续响应。合成 CPU 的这个界面功能尚未进游戏验证。
