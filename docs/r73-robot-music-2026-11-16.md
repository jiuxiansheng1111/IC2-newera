# 和机器人一起听歌

在工业手机的「音乐」里选择网易云曲目，打开「聊这首歌」，再点「播放这首歌」。开始出声后，可以先点「查看这首歌的公开短评」。选好自己的机器人后，输入一个问题，例如「哪一段让你想停下来听？为什么？」。游戏把短评摘录和机器人的回答分开显示。

想听它读评论时，可以问「读一条短评，再说你认不认同」。机器人聊天页的「语音」开关控制本机回复朗读，开启后会用现有语音服务排队朗读回答。

机器人的感想来自服务端对本次可播放音频的解码。它能比较开头、中段、末段的响度，也能找出有明显强弱差别的八秒片段，再结合角色的口吻和以往的看法回答。它可以说自己想到什么。仅凭这些数据无法确认歌词、乐器或作品背景。评论不可用时，页面会给出读取状态，仍可聊已经取得的听感。

停止播放、切歌或播放结束都会关闭本次讨论。之后可在同一机器人的聊天里问「上次听《晴天》，你为什么喜欢其中一段？」。同时提到两首以前聊过的歌时，它可以回顾自己的旧回答，比较感受。

## 听歌记忆

服务器按玩家和机器人各自的长期身份保存听歌记录。每组保留 32 首歌，每首最多四轮问答，包含时间、片段强弱、玩家的问题和机器人当时的回答。同一次播放里多次提问只计一次收听。记录随世界正常保存；换手机或把同一机器人收回玩偶后再放出，仍使用原有的记忆。问答会发送到所选模型，游戏存档保存文字观察。

## 模型设置

朋友导入整合包后，歌曲感想默认使用该游戏主机已有的 AI 设置。选择模型 ID `gpt-6-luna` 时，经所配置的 Responses API 发送歌曲资料和问题。选用该模型而连接失败时，游戏会报告失败。

安装了 QQ Cat Robot 的游戏主机也可以复用它已经登录的模型。在游戏实例的 `config/ic2newera-song-model-common.toml` 中使用以下设置，重启生效。

```toml
[music]
provider = "qq"
```

单人使用玩家电脑上的 QQ Cat Robot。多人使用服务器所在主机的 QQ Cat Robot，游戏通过本机回环地址的 8012 端口连接。朋友在另一台电脑上运行 QQ 不会为远端服务器提供模型。使用 `provider = "game"` 可切回游戏模型。打开短评只读取网易云公开资料。

## 实际核查

2026 年 11 月 16 日，网易云向匿名请求返回 RyaVocal 的《晴天（原唱 周杰伦）》（曲目 2668397359）。游戏的播放代码取得完整 4,332,717 字节 MP3，解码约 271 秒。公开接口返回三条短评，实际节选传给了本机 QQ Cat Robot。它的主模型配置是 GPT-6 Luna，单独的 Luna 推理请求也成功返回文字。

提问要求解释一条评论，再谈角色自己的喜好。模型正确引用其中一条，并把听众的说法和自己的感受分开。它说「我自己最喜欢大概 128 到 136 秒那段」，理由是那一段比开头更饱满，让它想到天色渐亮。

按游戏使用的 NBT 格式写出并重新打开机器人记忆后，简称「晴天」找到了此前的记录。第二轮没有播放音频，模型从记录里说出了同一个片段和理由。核查使用临时身份和临时记忆文件。另用模组客户端播放器向本机默认音频设备以低音量播放同一曲目，输出位置推进到 0.010 秒后正常停止。单人游戏窗口的手机按钮、角色语音朗读和退出世界后重新进入的全程操作还没有现场回执。

最终版另查了同曲两次播放、查询从未聊过的歌与空记忆。重新打开文件后，前者取回两轮，后两者返回零条。普通聊天不会替一个陌生的明确歌名编造旧感想。
