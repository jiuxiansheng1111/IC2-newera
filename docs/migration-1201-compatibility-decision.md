# 1.20.1 工艺缺口与已批准的兼容范围

2026-10-23用户明确回复“批准补齐兼容炉和缺失材料，继续迁移”。以下方案现已获准实施，不再等待范围选择；两炉和材料实现、构建及实机仍须分别验收。授权只适用于独立1.20.1新世界。

这是主代理审阅后的具体实施方案，尚未注册下列设备或材料。用户已批准独立新世界采用 IC2 Refactored；此次问题只涉及原规范未授权的新纪元兼容内容，不再询问是否采用 Refactored。

## 已完成的核实

锁定 IC2R 2.10.33-ex120 的注册器与设备字节码已读取。目标没有 Classic 合金炉和电高炉；其感应炉是两套独立普通熔炼槽，不能组合投入制造合金。其高炉依赖不同的热量/流体工艺，也不是 Classic 电高炉的直接替代。

当前三份 ProcessGraph 中，14 条合金路线依赖缺失合金炉，9 条高级熔炼路线依赖缺失电高炉/高温感应炉。严格加载会拒绝缺失引用。完整构建成功不代表这些工序可以运行；目前不宜安装后直接开始新世界验收。

## 建议方案：保留工序，补缺失能力

| 部分 | 具体实现范围 | 保留的约束 |
| --- | --- | --- |
| 合金兼容炉 | 新纪元命名空间注册一台 EU 多输入合金炉，复用现有受电、机器菜单、库存与工艺框架；读取 ProcessGraph 的合金配比、结果和批次 | 钢粉和其他合金仍在专门设备中组合投入；不改工作台或 Create 搅拌捷径 |
| 高级熔炼兼容炉 | 新纪元命名空间注册一台 EU 高级电炉，只接受 ProcessGraph 批准的高级净粉/合金粉工序 | 钛钨等不能降级到普通炉；能源、时间、箱子与实际运输进入同一生产线方案 |
| 缺失矿源 | 为银矿三个原有形态及粗银、下界铝矿及粗铝补本项目兼容注册与新世界来源 | 只补目标 IC2R 缺失的既有功能；旧世界不转换，生成频率与矿源在实施时明示 |
| 缺失材料 | 补铝粉/铝锭、青铜粉块，以及复杂电路、辉光储能晶体、UESC、高级合金板的明确兼容制作路径 | 新 ID 使用 ic2newera 命名空间，不冒充原 IC2 注册；原有净粉清洗、阶段和回收规则保持 |
| 联动 | 工艺注册/守卫、配方、JEI、科技树、BOM、机器人建线/改产、手机诊断和内置 AI 同步读取同一工艺图 | 没有另一份独立低成本配方；不用可选 tag 掩盖必需物品缺失 |

新增材料中，只有实际需要储能功能的物品实现目标 IC2R 的电池接口；纯制作中间体不伪造储能或沿用无法核实的 Classic 数值。机器数值、配方成本和能源等级属于显式迁移设计，不声称与 Classic 完全一致。不复制第三方机器源码、模型或纹理；沿用本项目造型规则制作兼容设备与物品。

## 为什么需要这次范围决定

当前 [AGENTS.md](../AGENTS.md) 第10条要求“加工新机器最多非金属处理机和电子材料加工机两台”；第14条要求“金属合金配料全走 IC2 合金炉”，第4条要求高级炉“不自造炉”。建议方案会让新纪元材料加工设备由两台变为四台，并以明确标识的本项目兼容炉承接 IC2R 缺口，因此不能在没有新指令时直接实施。

另一个选择是继续维持原设备/新增矿物限制，重新讨论受影响路线的改动范围；这不是本次已授权全部功能迁移的完成方案，也不能直接删掉这些路线来宣称迁移成功。
