# 新纪元 r68 · 机器人工具制作

## 派第一单

1. 在机器人旁边放普通工作台，旁边留出两格高的站位。给已充电的机器人主手或副手装备一把 IC2 锻造锤，在它的货物栏放 1 个铁锭。
2. 在机器人界面点「工作 → 工具制作」。通过手机打开同一工作页也能派单。它会走到台边、对准工件、举锤；接触时锤子消耗耐久，1 个铁锭变成 1 块铁板，放进货物栏。每次完成加工耗机器人 200 EU，通过手机成功派单另耗手机 100 EU。
3. 对它说「把上次制作记为备铁板」。补原料后，说「执行常用任务：备铁板」即可照原配方再做一批。「照上次再制作一次」可直接重复最近一次。服务器世界保存每台机器人自己的订单，也保留旧版的采集与烹饪记录。

## 其他可用工具

| 台面 | 工具和原料 | 一批产物 |
| --- | --- | --- |
| 普通工作台 | IC2 板材剪、铜板 | 2 根铜线 |
| 普通工作台 | Create 普通砂纸或红砂纸、玫瑰石英 | 1 个磨制玫瑰石英 |
| 农夫乐事的空砧板 | 厨刀、生牛肉 | 2 份肉馅 |
| 农夫乐事的空砧板 | 匠魂手斧、橡木原木 | 去皮橡木原木和树皮 |

首单根据货物栏先后顺序选择能与手中工具匹配的原料。锤板与剪线读取工作台的实际合成与余件，打磨读取 Create 的砂纸配方，砧板读取其工具条件与产出概率。可修复的匠魂工具损坏后要先修理。切刀、铁锤、板材剪和砂纸使用不同动作；森罗炒锅在原有翻炒生效后播放持铲动作。更多动作节奏与提示词见 [制作动作导演稿](robot-workshop-motion-direction-r68.md)。

## 中断与多人

走向台面和抬手时，原料仍在机器人货物栏。结算前会检查工具、材料、台面、权限、电量和货物栏空间，也会为砧板可能产生的副产物留位置。顺利完成后，旁边的玩家能看到台面上的工件换成成品。客户端与新纪元服务器须使用同一版 JAR，机器人频道为 17，工艺图频道为 36。
