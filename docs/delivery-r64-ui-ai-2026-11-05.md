# r64：界面文字、操作提示与内置AI知识库

## 本轮完成内容

用户要求改善新纪元界面中看不清或含义模糊的文字，并同步AI知识库、提供新版JAR。本轮针对独立Minecraft 1.20.1 / Forge 47.4.28工程修改22个界面；原1.19.2工程不变。

- 加工机分别展示储能、进度百分比及缺料、出料受阻、无电量、电量不足和加工暂停。输入槽说明与服务端允许的配方物品一致，补充槽位顺序和排查方法。
- 浅色工业界面正文关闭文字阴影，调整辅助文字与状态颜色；共享按钮截断时提供完整标签提示，显式用途说明保持优先。按钮提示交给原版最终提示绘制阶段，避免被后续按钮遮挡。
- 工业服务器解释配置权限、AI核心、开启控制、自动故障暂停和手动暂停的区别；电动机、发电机和变压器明确方向、电压及转速含义。
- 机器人、宠物、建造、烹饪、指定采集和货物栏补充条件、失败原因、暂停/继续/取消的实际影响。“杀戮”界面名称改为“攻击动物”，关闭时仍保留敌怪防御。
- 手机、音乐、网易云、歌单导入、虫洞、AI设置和资料来源补充用途及限制；长状态可以悬停查看。AI设置明确密钥留空保留、保存设置和保存后打开对话的区别。
- 内置AI新增`ui_operations_zh.md`并接入`LLMKnowledgeBase`实际检索，更新机器人说明及迁移运行说明；不是只在项目文档新增一份未加载文件。

审阅时发现“取消采集”原来只调用停止移动，却回执任务已取消。现改用现有取消任务方法，清除运行中或暂停的采集订单、进入待命，保留已收集物品；沿用所有权、在线/距离、电量、防重复回执及远程手机费用校验。成功取消仍扣机器人200EU，远程另扣手机100EU。此项必须服务器也替换r64 JAR才生效。

本轮没有改变配方、ProcessGraph、模型、贴图、注册ID或网络包格式，也没有恢复已停用的终端生产功能。
