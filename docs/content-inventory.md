# 当前内容清单

当前范围包括四种矿物、六种合金、装备、九种电子材料、两台材料处理机和工业网络，并保留科技树与 AI 助手。IC2 Classic、Create 及其他依赖模组的原生内容由它们各自提供；新纪元复用其电路与工程部件。

## 保留

- 四种核心矿物、六种新合金材料，以及既有的淬火钢、高碳钢、铝青铜装备。
- 非金属处理机与电子材料加工机；各自输入槽按服务端登记配方校验。
- 九种电子材料、工业光纤、网络交换机、工业控制服务器及 AI 核心。
- 中文科技树：介绍 IC2 Classic 与 Create 的原生玩法，并引导新纪元材料、机器和工业网络。
- AI 助手：使用者可以配置兼容 Chat Completions 的接口、模型 ID 与自己的 API Key。详见 [助手设置](ai-assistant-setup.md)。

## 不属于当前内容

化学实验、化学反应与化学加工线均已退出当前内容；此前版本内容不构成旧世界兼容承诺。旧存档可能含有不再支持的方块、物品或数据，升级前应按整合包/实例提供的备份流程处理。

## 使用边界

- IC2 Classic 与 Create 的机器和能源系统各自独立；本模组不把 EU 转成转速，也不把转速转成 EU。
- 跨系统联动通过物品配方实现；没有专用能源桥接。
- 工艺步骤与材料数量唯一来源是服务器同步的 ProcessGraph；AI、生产规划器和配方数据应读取同一份图，不另维护 BOM。
- 精确配方和当前可用配方由游戏内 JEI 确认，科技树用于说明阶段与路线。
- 只有游戏内实际加载并验证后，才能记录为实机验收通过。
- 旧 PCL 安装记录对应旧包体，不证明当前阶段已安装或验收。
