## 保留

- 四种核心矿物、六种新合金材料，以及低碳钢、高碳钢、铝青铜装备。高低碳钢材料各为粉＋锭，两种钢坯已移除；原有钢锭和装备注册 ID 保留。
- 非金属处理机与电子材料加工机；各自输入槽按服务端登记配方校验。
- 九种电子材料、工业光纤、网络交换机、工业控制服务器及 AI 核心。
- `ic2newera:eu_motor`：将 IC2 EU 单向转换为 Create 转轴动力，不反向发电。32/64/128 RPM 对应 1024/2048/4096 SU 与固定 10/20/40 EU/t；缓冲 10000 EU，从背面接收 LV 包，每包最多 32 EU。源码已实现，增量离线构建成功；最终构建与安装状态见[本阶段交付记录](motor-wifi-access-delivery-2026-10-08.md)，实机验收待完成。
- `ic2newera:wifi_amplifier`：交换机单槽升级，将默认 16 格球形 WiFi 扩展到水平 40×40 格、上下各 16 格；不能堆叠或串联，也不是独立方块。源码已实现，增量离线构建成功；最终构建与安装状态见[本阶段交付记录](motor-wifi-access-delivery-2026-10-08.md)，实机验收待完成。
- 工业服务器 GUI 仅有概览与联网设备两页：显示设备总数、运行数、异常数，以及每页 3 台设备的编号、名称、连接方式和状态；不显示流程、材料或坐标。名单限定为装有机器网络适配器并经 WiFi/光纤联网、或实际相邻光纤直连的设备。操作从设备行启动/停止；玩家须在服务器 8 格内，远端设备还须已加载、同网、实体身份一致并支持 `ControllableMachine`。所有玩家可只读查看和使用服务器 AI 诊断，当前配置权决定谁能确认提案；运行配置和控制仍按三档权限。AI 读取相同设备名单/故障状态，异常优先快照最多 16 台并附总数及未知、空闲、暂停、故障分类。终端库存权限继续独立使用 Owner UUID、当前队伍或管理员规则，不由“所有人配置”公开。
- 中文科技树：介绍 IC2 Classic 与 Create 的原生玩法，并引导新纪元材料、机器和工业网络。
- AI 助手：使用者可以配置兼容 Chat Completions 的接口、模型 ID 与自己的 API Key。详见 [助手设置](ai-assistant-setup.md)。

## 使用边界

- IC2 Classic 与 Create 的机器和能源系统保持独立；唯一能源方向例外是 `ic2newera:eu_motor` 从 IC2 EU 输出到 Create 转轴。转速不会转换成 EU，电动机也不会反向发电。
- 其他跨系统联动通过物品配方实现；电动机不会合并 EU 电网和转速网络。
- 工艺步骤与材料数量唯一来源是服务器同步的 ProcessGraph；配方、规划后端和 AI 规划应读取同一份图，不另维护 BOM。服务器 GUI 不展示流程/材料或规划页。
- 精确配方和当前可用配方由游戏内 JEI 确认，科技树用于说明阶段与路线。
- 只有游戏内实际加载并验证后，才能记录为实机验收通过。
- 旧 PCL 安装记录对应旧包体，不证明当前阶段已安装或验收。
