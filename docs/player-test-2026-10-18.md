# IC2：新纪元朋友联机测试包

本地源码与安装阶段：2026-10-18。重做科技树与助手预览，并修正手机音乐旧手工导入说明的显示、增加独立网易云红心列表入口。完整JAR离线构建成功，玩家保存退出后已安装本机PCL，尚未完成新界面实机验收或当前账户云红心验证。用户明确正常本地修改、必要编译和安装仍需继续；不需要的是给别人用的测试整合包、上传或发布。Tech-Tree ZIP未生成，下文分享包导入步骤仅适用于已有分享包或以后明确要求制作的包。机器人协议6、媒体协议7，联机更新两端须同版。旧 Robot-Care ZIP继续保留，其内容不包含本阶段改动。

已有 Robot-Care 分享包采用 CurseForge 格式：内置对应旧版新纪元 JAR，另外八个模组由启动器从固定官方版本下载，包含 Farmer's Delight。它不包含本阶段源码改动。分享包不带作者账号、登录令牌、LLM 密钥、私人配置或存档；首次安装需要联网，不包含 Minecraft 本体、Java、启动器或训练模型。

## 安装与联机

1. 使用 PCL 或 HMCL 的“导入整合包”，选择本 ZIP；PCL 也可把 ZIP 拖入启动器。导入为新实例，不要把 ZIP 放进 mods 或资源包文件夹。
2. 保持 Minecraft 1.19.2、Forge 43.5.0，使用 Java 17。安装后应有九个顶层模组 JAR，不要再添加另一份 IC2/Create/Flywheel。
3. 使用自己的 Minecraft 账号。多人服如开启正版验证，每个玩家需要自己的有效账号，不能用同一账号同时在线。
4. 进入“多人游戏→直接连接”，填写服主另外提供的服务器或 TCP 穿透地址。包内没有预置私人服务器地址；客户端与服务端必须同版。
5. 房主使用白名单时，先把自己的游戏名告诉房主加入白名单。公开转发只需 Minecraft TCP 端口；不要公开语音工作进程端口。

核心版本：新纪元0.1.0-dev、IC2 Classic 2.1.3.4、Create 0.5.1.i、ProjectE 1.1.0；配套 Carbon Config2.0.2、Curios5.1.6.4、The One Probe6.2.2、JEI11.8.1.1034、Farmer's Delight 1.19.2-1.2.4。Create 自带所需 Flywheel/Registrate。固定官方来源见 modlist.html，哈希见实例 IC2-New-Era-Test/mod-lock.json。

## 这版包含什么

- 八角色机器人娃娃共用一张图纸，无成就解锁门禁。可放置、查看信息、跟随、待命、收回、装备工具/防具、伐木采矿及切换攻击敌对生物。
- 机器人电池400万EU、物品等级3；普通储电箱用MFSU/ESU等相容等级，IC2充电台/电池站单独充电格原生支持跨物品等级。五次死亡寿命，死亡清空已装电池。满电在20TPS、实体加载且无额外操作时，待命/普通跟随约24小时，持续工作/攻击约6小时；聊天与远控另耗电，未加载不模拟离线耗电。
- AI助手及机器人聊天同步充电、电压、变压器、事故条件和物品玩法知识，可检索已安装IC2自带手册。原LLM配置不改；实际回答效果请使用自己的模型验证。
- 配置好语音环境的主机随游戏自动启动轻量语音后台，游戏退出后回收。模型加载前需1GiB空闲物理内存，不足时等待；TTS/RVC串行加载，最多16条FIFO等待，每条从入队起最多10分钟。运行极低余量硬线0.25GiB，提交量/磁盘保护保留。普通助手与机器人均可持续分段朗读、暂停/继续/重播/停止，关闭对话页不中断；退出游戏删除生成音频。远程客户端无需Python或模型；训练模型不随整合包分发，本地单人需先有相应环境/资产和本机运行时配置。
- 初级/中级/高级/核能充电宝为IC2等级1/2/3/4。副手自动给兼容物品充电，玩家背包自动给手机充电；机器人货物格中的高级/核能充电宝可给已装三级电池补电。核能使用有限燃料，非无限能源。
- 手机采用中后期电子材料加工机配方：机器人控制核心、SSD×2、GPU、UESC、复杂电路×2、高级充电宝；2400tick、256EU/t。手机支持设备状态、机器人命令、角色远程聊天/语音及音乐页面。
- 终端改为箱体主体，原有144格网络存储保留。材料、矿物清洗与工业路线沿用当前 ProcessGraph，配方以JEI/科技检索为准。

## 手机点歌

1. 给手机充电，玩家自己放置交换机并设置网络名；在有管理权限的Wi-Fi覆盖内，手持手机右键进入音乐页面。
2. 选择网易云或 Audius 来源，输入歌名点击搜索，结果会自动显示；选择曲目后再点“播放所选”，搜索不会自动开始播放。网易云优先用原助手模型理解点歌；仅模型未启用或理解失败时回退普通目录搜索，原LLM设置不变。Audius沿用公开目录搜索。
3. 验证收藏、移除、上一首、下一首、暂停/继续、停止，以及播放完自动下一首。关闭页面可继续听歌；自动下一首需背包有带电手机且仍有Wi-Fi权限。
4. 每位玩家的歌单和播放独立。音量跟随游戏“主音量×音乐”，同一歌曲不向全服广播。请用可公开取得的完整歌曲；会员、付费、试听或下架曲目可能被明确拒绝。

“我喜欢的音乐”是已登录网易云账号的云端红心列表，与游戏内“我的歌单”分开，不会替换原游戏歌单。只允许本机房主或专服指定房主使用自己的音乐登录会话读取，其他玩家不能读取其账号列表。列表按100首分页；平台返回、账号有效性及本次列表读取仍需实际验证，不能把按钮出现当作已成功读取账号歌曲。

导入、网易云登录和刷新集中在“更多”菜单。当前紧凑布局在427×240 GUI单位下为两行歌曲，播放器和真实状态分别保留区域；更小窗口、字体/资源包及不同GUI比例仍需实际确认。

导入页支持公开歌单链接或ID，网易云另支持按“歌名 / 歌手”逐行填写或歌曲对象JSON。手工条目在服务器媒体工作线程串行联网核实，读取真实歌曲编号、歌名和歌手后才整批替换原游戏歌单；未匹配、歧义、网络错误或取消时不覆盖旧歌单。最多100首，有约150秒核实预算及逐项进度，可用停止/取消中断；不要粘贴聊天说明或日志。普通搜歌无需准备JSON或文件。

旧版曾把粘贴的整段聊天说明直接存成手工歌名。因此音乐列表里曾出现“语音目前还没接入完成”等旧文字，实际是用户导入内容，并非游戏固定语音能力提示。旧 `query:` 条目统一显示“待核实导入内容”，悬停标明“原始导入内容（不是系统提示）”并保留原文供辨认；可“核实并播放”或手动移出。没有自动删除或修改旧存档。合法旧手工歌曲仍需服务端准确歌名/歌手匹配成功才播放；需重新导入核实为真实目录条目后才能生成翻唱。

音乐页的“网易云登录”可显示官方扫码入口，默认打开“记住登录”。单人或开放局域网由开房玩家登录；专服需由管理员在服务端 `config/ic2newera-media-common.toml` 的 `[music_login]` 中填写唯一房主 `ownerUuid`，留空不开启账号登录。普通玩家和其他OP不能接管该会话；Sakura等TCP穿透沿用相同规则，不另开放登录端口。其他玩家仍使用匿名公开音源。

凭证只保存在运行游戏服务端的电脑：单人/局域网在房主电脑，专服在服务器磁盘。Windows使用当前系统用户加密，Linux使用私有目录和文件权限；本机安全存储不可用时仅保留当前运行会话并显示原因。凭证不进入LLM、玩家存档、客户端同步或整合包，也不会发给开发者。“记住登录：关”删除本机长期文件但保留当前会话，“退出登录”清除当前会话和本机文件；平台让凭证失效后仍需重新扫码。不要把实例中的 `config/ic2newera-private` 目录发给别人。

网易云自然语言点歌使用原LLM并可回退目录搜索；云端红心列表、导入歌单、收藏和播放不调用LLM。原曲音乐由Mod内Java实现，不需要QQ/AstrBot/Python/FFmpeg；角色翻唱仍需下述独立环境。

选中歌曲后可选择自己的在线机器人声线，再点“排队生成翻唱”。翻唱需要服主的可选 Demucs/RVC 环境与角色模型；源曲不超过360秒和16MiB，输出上限80MiB，与语音共用串行队列及资源门禁。停止/取消会取消生成，原曲播放按钮保留。Audius条目显示来源、作者和曲目页；是否允许翻唱按实际歌曲授权判断，公开播放不代表自动允许二创。

## 科技树与助手预览

科技树采用工业蓝图主题、物品图标，从底部主干向上分支。分支主线帮助浏览，真实多前置连线、服务器科技进度和解锁条件保持原逻辑，不新增配方、材料或科技门禁。助手内预览与全屏树复用同一布局及主题。

画布内左键或中键拖动平移，单击节点查看右侧详情；滚轮围绕鼠标位置缩放，也可拖动缩放条或使用加减按钮。“复位”或未聚焦搜索框时按Home返回起始视图，“适配”显示当前筛选范围。顶部可搜索名称、说明和分支，并切换分支；右侧长详情可滚动。新布局、图标、裁剪、不同窗口和GUI比例尚待本阶段游戏实机验证。

## 自动采集与料理锅

指定采集按实际掉落物选择方块：例如目标泥土可以挖草方块，目标草方块本身则要求相应精准采集工具。机器人从主手、副手、货物槽自动选镐/斧/锹/锄/剪刀或适用IC2电钻、电锯，自动交换原主手，保留工具数据。实际挖掘仍走原生掉落、工具耗电/耐久和保护事件。范围采掘工具需切单方块模式。无合适工具、工具等级/电量不足、背包满、目标不可达或受保护时会通知主人，不会把未入库物品计作完成。

直接说“挖矿”“伐木”“跟随”“待命”“做饭”可触发固定工作命令，不需要模型解释；定量任务继续使用原模型和服务端校验。普通挖矿寻找工作点附近已加载的露出矿石，不自动开贯穿全图的矿道。

做饭时，在机器人工作点附近放置带有效热源的 Farmer's Delight 原生料理锅，九格须为空；机器人货物格提供配方原料和对应数量餐具。机器人走到锅边、复核权限后投料，由原锅计时和生成菜品，再收入货物。当前不支持有无法追踪食材容器余物的配方；缺材料、餐具、热源、空间或通路会提示。任务绑定原锅，切模式暂停；“取消烹饪/重置烹饪”解除绑定，已投入物料留在原锅。第三方自动化改动锅时会因快照不符暂停，不能保证所有模组物流都被锁定。

## 角色语音与模型

机器人文字和点歌已迁入Mod，不再经过QQ。单人模式使用玩家自己的原助手模型设置；新实例默认不配置模型，不包含任何人的密钥。专服由服主在服务器 config/ic2newera-media-common.toml 配置模型，不能把这个文件发给玩家；玩家的个人密钥不会上传给游戏服务器。

角色语音是可选功能，先由玩家在机器人页面打开。服务端主机需要运行已配置八角色TTS/RVC资产的独立语音进程，地址保持本机127.0.0.1:9881；远程玩家仅安装此整合包即可接收音频，不需要模型或Python。**仅把客户端包发给别人，不会自动给对方电脑安装训练模型；单人语音需自己准备相应语音资产。** 语音失败会保留文字回复。

包中 `tools/robot_voice` 只带公开运行代码和 `ic2newera-voice-runtime.example.json`；房主有自己的合法模型与环境后，按示例创建本机 `ic2newera-voice-runtime.json` 并填写实际路径。实际配置、训练模型、音乐登录凭证及历史生成音频都不在包中。翻唱另需示例中的可选 `singing` 环境；未配置时不会擅自下载模型。

手持有电手机右键，自己的机器人会自动出现在联系人中；联系不限格数，可跨维度，不要求同一WiFi组件。选中在线机器人，点击“角色聊天 / 语音”即可接收文字和角色语音。目标区块未加载时显示离线及最后位置，不远程强制加载区块。一次聊天手机100EU、机器人2000EU；电池/装备和收回仍在身边操作。工业设备和音乐仍使用原WiFi/光纤网络。

角色页支持语音开关、暂停/继续、重播上一条、停止以及跟随、待命、战斗开关。返回设备列表切换机器人时，各自对话/草稿分开保留（单次手机界面会话上限16个，非永久存档）；关闭会取消未完成的文字请求，已排队语音继续。目标卸载、死亡或所有权改变时，服务器会取消未完成请求。

手机联系人/角色页面和机器人近身页面均有“指定采集”：输入物品中文名或ID，选目标和1～256件，选择自动采矿/伐木及拾取，或仅拾取现成物品，再确认派发。工作只覆盖机器人任务开始点附近已加载区域，需要真实资源、合适工具和货物空间；进度只计本任务实际入库数量，足量停止，超出的掉落留在地面。任务接收/取消收机器人200EU，手机远程另收100EU，失败不扣费。跟随/待命/普通工作会取消指定任务；任务和进度存档保存，收回再放置在新位置继续剩余数量。不自动合成粉末/锭、不强载或全图找矿。

也可直接在手机角色聊天或近身对话输入“帮我采集20个钨矿”“请采集二十个钨矿”“帮我捡3颗钻石”，不用打开选择页。沿用原LLM识别本轮一个目标、整数数量及采集/拾取模式，服务器重新核对原文数量、真实注册物品和权限；缺失数量、名称重名或意思不清楚会追问，不能靠模型编造ID派单。聊天机器人2000EU照常，成功派发再收200EU；手机本轮聊天已收100EU，不重复扣手机费用。回执可按当前角色音色朗读；以“已接收采集任务”及状态页进度为准。知识咨询、假设、否定不会自动变成采集任务。没有活动任务时点“取消采集”不会收费或改变当前模式。

语音模型开始门槛为1GiB，是系统空闲内存条件，并非模型只占1GiB。资源不足会等待，达到条件才加载；一次只生成一条，TTS退出后才加载RVC。八角色均已在专用单人世界通过各自实体页面真实LLM→对应角色合成→非零音量游戏播放完成，运行时模型映射和客户端音频哈希一致。长回复两段顺序播完，生成期间暂停、跨窗口恢复、缓存重播/停止和退出自动清理均已检查；每段生成后播放，段间可能等待。听感与各角色音色质量需玩家试听确认。

## 请朋友重点验收

1. 八个角色分别放置、装电池、聊天并开启语音，确认声音确实来自当前角色，关闭语音后不再播放，切换回复不串音，收回与重进后状态正常。
2. 手机通过真实LLM点一首公开可播放的歌曲，验证歌单导入、上一首/下一首、暂停继续及音量；记录模型/网络错误提示，不要发送密钥。
3. 两位不同账号、非OP、不同队伍同时在线：各自放置机器人和交换机，各自建歌单；确认B看不到/不能控制A的机器人，不能更改A的歌单，声音不会串到另一人。
4. 一位玩家本地连接，另一位通过服主提供的真实公网/TCP穿透地址连接；重复聊天、语音、歌曲播放，并验证断开重连、服主正常重启后的持久化。
5. 顺带确认手机实际合成、IC2等级充电限制、机器人背包自动补电、工作/攻击耗电、死亡与收回；检查不同窗口大小/GUI比例和装备拖放。
