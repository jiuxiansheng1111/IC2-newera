## 矿源、资源与流程读者

银净粉与银锭复用IC2R，银三种矿形态及粗银、下界铝矿/粗铝/铝粉/铝锭、青铜粉块和高级中间体用新纪元命名空间补缺。正常采矿掉粗矿、时运可增量；精准采集保留矿石，运输后仍遵守原图的杂质粉/清洗阶段。新世界生成参数：

- 主世界银：size 6、每区块4次、Y=-48～48三角分布，石质和深层按地形替换。
- 下界银：size 5、每区块3次、Y=16～96均匀分布。
- 下界铝：size 7、每区块5次、Y=16～112均匀分布。

只作用于新生成地形；不操作旧世界。新锭保持原版铁锭像素轮廓；矿石/粉/部件和两炉均是本项目资源。两炉正侧/等轴r3图已由主代理逐项查看，修正侧面共面问题；游戏外观仍待验收。生成器、必要像素脚本和铁锭校准基准一并放隔离art目录，不依赖主项目路径。

机器人继续用整齐固定机位和共用电源、电缆干支线，负载取本线路同设备各工序中的最大EU/t，保留15%供电余量。三种合金输入可记录/恢复；模拟投料/回收后才移动实物，满箱和堵路保留任务。JEI兼容炉分类显示两种实际设备、全部配料、耗时和耗能。手机/ICCN读取Processor实际库存、能量、进度并支持暂停。科技树与内置AI从批准图读取材料路线，AI补充本版边界。

电子加工机/非金属处理机仍由玩家或ICCN操作，当前机器人矿物/合金场站不会自动建它们，也不自动合成全部施工设备。这个既有场站边界没有因材料BOM增加而扩大。
