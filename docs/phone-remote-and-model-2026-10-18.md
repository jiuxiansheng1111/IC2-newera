# 手机远程语音、外观与指定采集交付（2026-10-18）

本阶段承接用户最新要求：游戏内手机接收机器人角色语音、联系不限距离，手机和近身界面均可派发指定矿物或物品采集；手机改为现代薄型立体外观，游戏名称统一为“手机”。原 LLM 配置未改。下方把实现、安装与实际验收分开记录。

## 已实现

- 自有机器人自动进入服务端联系人目录，联系不受距离、维度或同一 WiFi 组件限制；仍验证服务器、UUID、所有权、实体存活/已加载、电量和持有手机。离线保留最后位置，不为联系功能强制加载区块。目录上限每人64、全服8192，不复制实体。
- 手机联系人中进入“角色聊天 / 语音”，服务器绑定实际机器人 UUID/角色，沿用原模型和原分段语音队列。可暂停、继续、重播、停止；返回和切换联系人保留各自会话及草稿（单次界面会话最多16个），已排队音频继续，未完成文字请求关闭即取消。普通设备及音乐仍遵守工业 WiFi/光纤规则。
- 手机联系人、电话页和机器人近身页都有“指定采集”。输入中文名或注册 ID，选择1～256件以及自动采矿/伐木并拾取或仅拾取。自动模式只处理真实掉落可产生目标的矿石/原木，需要匹配工具；范围为任务工作点附近已加载区域（横向±6、纵向-3～+5）。遵守原生破坏/保护事件、工具耐久及货物容量，计数只记本任务实际入库，足量停止，额外物品留在地面。
- 任务接收/取消耗机器人200 EU，手机远程另耗100 EU；失败不扣费，相同活动任务不重置；服务端有限回执缓存防同一请求重复执行。任务和进度保存在实体/娃娃 NBT，重新放置后以新地点继续剩余数量。跟随、待命和普通工作会取消指定任务。不会凭空生成矿物或绕过 ProcessGraph 合成粉末/金属。
- 手机名称改为“手机”，注册 ID 保留 `ic2newera:industrial_phone`。原创薄型金属机身、正面黑边屏幕与摄像岛、背部三枚凸起镜头和侧键；12个立方元素，128×128分区UV贴图，独立可复现生成器和真实UV模型预览。实际第一人称屏幕朝向玩家；不下载或复制商业资产。
- robots/media 协议统一为5；客户端、服务器必须同时更新。原材料路线、电池/配方和 LLM 参数未改。
