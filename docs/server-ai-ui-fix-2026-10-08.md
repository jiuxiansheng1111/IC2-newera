## 问题与修改依据

旧服务器在同一个小面板堆叠状态、规划、坐标和控制按钮，核心槽又靠近状态区。旧 render 调用先绘制有物品的常规 tooltip，再绘制核心用途 tooltip，导致同一位置两份文字叠加。现改为独立核心区和三个页面，合并为一次 tooltip；允许物品、用途、无核心/权限不足说明仍由槽位提示提供。

旧 LLMChatScreen 继承 Screen 的默认暂停行为，单人集成服务器会暂停；服务器快照通过服务端队列处理并有5秒超时，该页暂停会使查询不能及时返回。现在聊天及提案确认均不暂停世界。窗口 resize 重新创建控件保留草稿和请求；关闭或外部退出取消当前异步阶段，迟到回复由请求编号过滤。返回时核对原容器仍是当前菜单且有效。

聊天页面不再按完整长说明高度挤占内容区；顶部说明提供悬停全文，底部状态最多显示两行并保留完整悬停文本，发送输入框独立固定在底部。服务器菜单固定300×226，菜单/屏幕共用槽位坐标，按Minecraft原生GUI比例定位，适用于标准320×240及以上GUI尺寸。更小的非标准GUI未验证。
