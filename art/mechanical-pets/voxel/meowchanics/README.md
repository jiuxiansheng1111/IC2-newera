# 老吴学职业装备体素预览

此目录包含 13 份 Blockbench MCP 可编辑职业装预览，基于项目已认可的 `../cat/cat.bbmodel` 第一方副本。原猫体形、面部、翅膀、尾焰均未改动。每个职业添加独立整数 cuboid；静态旋转为零。

- `career-outfit-index.json`：来源、几何索引、三视图、哈希。
- `career-outfit-mcp-operations.json`：可复现的 MCP 添加操作。
- `career-<职业>.bbmodel`：13 份可编辑源。
- `<职业>.png`：原创 16×16 限色调色板。
- `<职业>-front.png`、`<职业>-three-quarter.png`、`<职业>-back.png`：Blockbench MCP contact sheet 多视图。

职业范围：terminator、fishing、flight、fire、honey、transport、dynamite、engineering、medical、music、agent、diving、cockroach。未拷入老吴学第三方模型或纹理。
