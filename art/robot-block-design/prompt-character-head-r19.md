# 八人额前发型 R19

R19 是独立于 R18 的新头部草稿。R18 保持冻结。主代理已经审阅 R18：薄束比厚根桥改善，但八人右侧仍有冠前黑色贯通三角孔；额前只有少数直束，覆盖不足；多数发尖停在 y=25 左右，高于脸顶 y=24.565，没有落到额头。

爱音与爽世先作为形态基准，主代理审阅后允许扩展其余六人。每次修改先读取 MCP 当前修订；渲染文件名须带本轮模型 revision，不能覆盖之前用于审阅的图片。回执记录 MCP 实际返回的路径、模型 hash 与 revision，不假定或硬编码下一次 revision。

## 几何要求

在冠体与额头之间增加 6–8 层隐藏在外主束后的阶梯长方体发底，填合左右侧视与三分之四视里的三角透光孔。每层形成真实体积，沿头顶至额顶顺着外束后缘逐层改变前缘 Z；同一 Z 面不能贯穿整段高度。逐层查看该高度外束最靠后的实际位置，将发底前缘向头内（+Z）退约 0.12 单位，后缘嵌入冠体/脸侧实体；层与层沿高度、深度均交叠约 0.08–0.12 单位以连成一体。发底必须藏在外束后，正面仍看见连续分开的纵向/侧扫发束，不得露出横板；不盖住眼眉，不做外露厚桥。一条悬空的薄斜面或只抬高束根不算闭合。逐人核对实际冠体和脸顶坐标，按角色头宽、发束弯线及发缝裁切每层宽度；两侧剖面均不得透出背景。

每人用 5–7 根错落、有序的绕 X 轴旋转薄长方体发束，足够覆盖前额宽度。根端约从 y=27.3、z=-1.3 一带接入冠前；发尖落在 y=24.0–24.5，低于脸顶 y=24.565，通常高于眉毛 y=23.6。束宽、间距、斜向和长度按角色变化，避免等宽等距的栅栏。可以让主束相接或略有重叠，形成连续发际线；保留可辨认的发缝与方向。

角色目标：

- 爱音：偏分侧扫，束线向一侧流动，长脸侧发仍保留。
- 灯：短而齐的刘海，中间分成几束小发束。
- 爽世：中分双帘，保留中间窄额头，左右各有独立方向。
- 立希：较整齐的齐刘海。
- 乐奈：较短、不齐并轻微中分。
- 祥子：明显侧扫。
- 初华：细碎齐刘海。
- 海铃：反向侧扫。

保留 R18 的脸型差异、发色眉、五官和侧发；不改 R16 眼、鼻、嘴的位置。身体、服装、饰品及头部以外所有几何/层级/纹理须保持基线指纹。不得导入游戏运行时，不复制外部模型或纹理。

输出可编辑 `.bbmodel`。爱音与爽世试做先提交主代理审阅；其反馈确认两人的侧扫束/中分帘差异和冠前连续性可作为其余角色的 R19 候选基础。该反馈只授权扩展候选，不代表八人视觉验收完成。

## R19 外层发束修订

保留已补上的内层闭合几何，只替换外主束。使用现有发色调色板的主发色与相邻深色；不要把每根都映射到同一个 UV。邻束沿 Z 前后错开 0.08–0.16 单位，根部继续与冠体搭接；外束由 2–3 段薄长方体首尾重叠约 0.12 单位，弧线保持连续。发尖按角色分成 2–3 个不同高度，不低于眉毛，不遮眼。

爱音采用清晰的偏分侧扫主束并留小分缝。爽世每侧做 2–3 段薄束组成的中分帘，向外弯出弧线，不做从冠顶直落至额头的柱状帘。角色标签与视图标签分行。每次编辑前读取当前 MCP revision，渲染文件名加本轮模型 revision，已送审图不可覆盖。
