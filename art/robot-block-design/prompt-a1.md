# A1 原生方块设计目标

2026-10-14，按用户最新要求由 Astra 亲自重新设计。先爱音与祥子，其他角色暂不冒充完成。

头和身体以 Minecraft 方块语法重新设计，不从旧曲面体素化。方头、平整脸面、完整后脑；头发只以少数有意义的长方体分组表达顶盖、侧扫刘海、侧发、后发与角色饰件。每束连在发根，长发用三至四层大尺度收束，不排列密密麻麻的碎石。衣服有肩袖、衣领、腰、裙层、裙褶与鞋袜，机械接缝克制。全部可见几何均为非零厚度的原生长方体。

爱音：粉色偏侧扫刘海，左侧（观者右侧）双发夹，长发及腰；眼型明快但不用Q版大眼，灰蓝虹膜有眼白、深瞳、克制高光，两条眉独立，鼻侧两至三像素，开口笑含极少牙白；演出服蓝短上衣、金黄领部饰边、露腰、白色前短后长裙、黑短靴。

祥子：蓝灰色方块发顶、左右连续编发接耳后黑结，卷尾用少数有方向的阶梯块，不作柱状发条；琥珀色稍沉静的眼睛、柔和独立眉、小鼻侧影与闭口浅笑。灰蓝开衫、白衬衫、深蓝领带、绿格裙、白及膝袜、黑鞋。

五官原创64逻辑像素，皮肤只用少量像素色阶，不作连续柔光渐变。眼睛位置与刘海一起检查。所有材质区直接生成原创，不读取历史角色贴图。正/左右斜前/严格侧/后和脸部近景由Sol渲染实际cube，再由Astra看图改几何。不能把文件通过或cube数量当作审美通过，不评分。
