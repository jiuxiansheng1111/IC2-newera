## 实际制作顺序

1. 真实读取全部额度，普通可用且所有适用窗口剩余 >1% 才改源。先保存本轮前源码状态，A6 首稿冻结目录不可改。
2. 从无损原图确定两眼中心、眼角、鼻口、下巴与可见脸缘，保存明确的源坐标和图上的标记。先校正眼线倾斜，并根据同一原图收敛眉眼口比例；不凭空画一套新的眼睛。尽量保留原采样颜色与眼型，所有重投影/遮罩/补边必须可解释。源图只有几十像素的脸，不得称补出高清细节。
3. 在原图脸部区域建立一致的正面 UV 底稿：五官来自用户明确要求的原图像素采样；头发、上衣、白背景从脸部 chart 排除。只允许必要的皮肤底色补齐与角度/投影校正，不能把眼睛、嘴抹成另一种表情。先输出原图 → 坐标校正 → 最终 UV 的对照，亲看实际图片。
4. 为这个布局重新校正可见脸面积、额角、脸颊、短下巴、头宽与肩宽。连续主脸和少量浅收口承托，不沿用 A6 大梯形前板作成品，也不做42横条/36°双斜下颌。正面鼻口不能被几何高差拆开；侧面不能成为贴在方盒上的面具。
5. 头颈连接必须同时在正面与严格侧面自然：头的下方真实接到短、较窄且后置的颈，领口之间只露合理的长度。颈属于头部/颈范围允许重做；身体、肩臂、演出服、裙腿鞋保留 A6/A4 数据，不借修头更改它们。必要的边缘承托可在头发内隐藏，不能靠阴影隐藏粗柱、叉尖和接缝。
6. 刘海走势服从原图侧扫轮廓，细分用于转弯与收尾；没有固定层数/节数/方块数量。侧发包脸、后脑完整、长发有厚度和发量。保留 MC 的有方向长方体发束，避免大平木板、屋瓦、梳齿、重复强条纹。发夹方向、脸的左右与 North UV 不镜像。
7. 导出独立可编辑 `.bbmodel`、实际几何 JSON、PNG、正/左右45°/严格左右侧/后、头部近景及正常尺寸图。原图、A6 与本轮使用统一方向/光照/裁剪对照。明显失败先修实际资源，不靠评语宣布成功。
