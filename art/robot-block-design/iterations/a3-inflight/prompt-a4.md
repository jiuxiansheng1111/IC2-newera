# A4 用户纠正：零件方块，不是整脸正方盒

2026-10-14 用户明确指出：“这什么方块脸完全正方形一点都不像，改一下，太粗糙了”。此前把方块语法理解成整个脸一个大正方体是错误方向。立即暂停其他角色和服装扩展，先改两名头脸原型。

每一个零件仍为有厚度原生cube，但整体脸型按太阳穴、颧骨、脸颊、内收下颌、短下巴分段。以十个左右横截面、每片三至五个宽段构成连接的阶梯头部；颊侧前后深度细微退让，不能一个大皮肤侧板。各前脸段统一以整脸世界坐标取同一原创脸图，不能重复或拉伸五官。保留鼻口清楚，眼位和眉眼间距与新脸型一起校准。

头顶发壳也跟随上额收束，用几层宽台阶而不是平顶盒盖；不回到曲面mesh、不导出平滑法线、不以极小碎块模拟雕塑。发根、两侧发和后脑保持相接。先看头部正面、左右斜前、严格侧与后面，明显方盒/尖下巴/锯齿脸继续改。
