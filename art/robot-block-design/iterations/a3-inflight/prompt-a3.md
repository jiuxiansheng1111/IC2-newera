# A3 实际多视角后修订

A2已亲看全身六视图、爱音脸和祥子右斜前。裙横层消除，但窄块贴满整张64材质导致发向/格纹压缩重复；侧面露肤像大片侧板；衣服仍太像无细节盒子。主线审阅也指出爱音U形嘴底孤立像素像胡须、眼下斜像素像眼袋，祥子裙直筒、卷尾细。

先纠正UV物理尺度：发丝与格纹按世界坐标连续取样，不能每个窄块塞满相同全图。爱音开口笑改为连贯、小而非U形的嘴内形状，去掉孤立下巴像素与眼袋；祥子降低眼高，保持眼白和琥珀虹膜。补后侧发遮住不必要露肤，耳侧只留有限面颊和小耳根。祥子卷尾变成较饱满的阶梯S形，不能悬浮。爱音蓝短袖有独立袖口、腰部收束和蓝金翻领，去无依据白胸牌。鞋面与靴筒贴图区分，不反复印鞋带。裙外褶阶梯只在外轮廓，正面连贯。
