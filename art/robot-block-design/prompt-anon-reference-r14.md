# 爱音 R14：按用户提供的 Blender 参考重建方块头部

本轮主智能体亲自建模与看图。以 `ano by很ying的哈呵.zip` 的实际网格/UV检查视图作为形状与配色参照，原包只读；不搬运第三方网格、贴图、骨架或动画。保持 Minecraft 的可编辑长方体结构。

用户最新授权覆盖 R13 的头部冻结：保留 R9 身体、四肢、裙摆、组结构和枢轴；脸型、五官与全部头发允许重建。身体 51 件与原 8 张贴图逐字段核对，主工程中不放取景辅助块。

## 制作前判断

- R13 下颌平宽、脸部留白大，眼睛灰浅；光改眼睛不能解决整体比例。
- 参考是连续脸面，脸颊逐渐收向短下巴。采用少数相交的同色长方体形成连续平整脸面与倾斜颌缘，不用密集肤色台阶，不造球体。
- 蓝灰大虹膜、较小瞳孔、深上眼线和浅下缘共同构成眼神。使用统一小方格重画眼睛，保留少量眼白，不画成整颗苍白圆盘。
- 眉毛按既有用户要求保持细黑色，和上眼线分离；嘴保留单个短横长方体。眉眼嘴作为一组校准，双眼位置整齐，高光方向一致。
- 发型先形成圆润冠顶、偏分弧形刘海、两侧遮颊短束、连贯侧后长束。每束沿确定的路线连续转折并收尾，不随机拼碎块；用长方体的真实体积表达，不导入参考曲面。
- 头顶、脸宽、眼位与下巴相互校准；头部接领口，不恢复外露脖子。保留 R9 衣服和展开裙摆的比例。

## 审阅与交付标准

1. 生成真实正面、斜面、两侧、背面、全身与常规尺寸图，亲自检查。对照 R13 和原参考时注明参考的非最终 Blender 材质限制。
2. 脸颊/下巴的收形须实际可见；正面不能出现宽水平下颌或眼睛被发束切掉。侧面不能出现突出的肤色托架、外露颈块、悬浮眉眼。
3. 发束走向连贯，刘海遮额但保留眼睛，左右发束收住脸颊；顶冠与后脑无露肤孔，避免大块横向断层。
4. 不以方块数量、主观分数或静态检查代替外观验收。保留可见局限，不宣称相似度达标。
5. 每轮修正先在此记录判断，再更新模型；保留前一轮候选和真实图片。

仅爱音静态资源。不开游戏、不构建、不安装模组、不运行测试或 self_test；不查询额度、不恢复旧心跳、不委派。

## 第一轮实际看图后的修正

正面下颌两角比中央底边更低，形成小尖角；侧面后半头皮暴露，因为侧发宽度轴未沿头部深度展开。两项均不通过。第二轮将颌缘改成两段连续斜边并与短中央下巴齐底；侧发改为沿深度相接的完整发束层，根高随冠顶轮廓变化。额头上缘藏入刘海，避免矩形肤面边线。虹膜下缘去掉重深圈，增加上下连续的蓝灰明暗和圆形高光层次。R9 身体仍冻结。

## 第二轮实际看图后的修正

侧面覆盖和颌缘改善，但加高的平直额头穿过刘海，形成横向肤色边；这是模型问题，不能交付。额头改为向后收的倾斜体积，主脸到眉上即收口。去除独立颈连接块，脸部体积向后连到领口，整个新头部下降 0.6 单位接合 R9 原领口；身体保持原坐标。刘海分段长度略作区分，减少整齐横排接缝。

## 第三轮实际看图后的修正

已消除下巴两角及外露颈块，后侧覆盖完整；但额角仍有两块被刘海切开的肤色三角，破坏连贯偏分轮廓。将刘海内部承托改为粉色后衬，并收入发束后方；保留眉眼上方自然露肤区，不在额角暴露矩形肤面顶边。主脸、眼、颌缘和全身比例保持此轮。

## 第四轮与原参考对照后的修正

Blockbench 正面取景的屏幕 X 与前轮参考提取渲染相反，主刘海扫向需要镜像，避免把偏分方向做反；镜像仅作用于新头发，不动 R9 身体。双眼高光统一调整到参考的屏幕右上方向。背面冠顶交界仍有两个小肤色点，将被头发包围的后脑承托明确改为头发内部填充体，避免细缝露肤。所有更改后重新生成完整视图。
