# A2 看实际图后的修订

A1六视图与五官已亲看。问题：眉毛拱成玩偶表情；眼睛下缘与虹膜太方；祥子嘴角过扬；爱音露腰偏长；发层没有足够发向；裙子明显三层横蛋糕，祥子编发相邻块共面产生细小闪纹。不能扩到八人。

A2：重新画小一号非对称转折的动漫像素眼，留眼白、虹膜、短瞳孔与一个高光，眉毛收平并按爱音/祥子分别处理。去掉直条腮红，鼻尖两像素、嘴唇克制。爱音保留开口笑但缩窄。刘海改为六至七个不等宽/长的连接块并以方向性像素表现侧扫；头顶仍是方块。后发分成三个互接大束，以有限高差收尾。祥子编发取消共面交叠、放宽卷尾横向变向，不做细棍。衣裙横层改成纵向裙片，每片是连贯长方体，靠相邻前后深度和末端长短表现褶裥；保持原服装色与前短后长。
