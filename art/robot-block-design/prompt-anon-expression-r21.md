# 爱音 R21 日常与说话表情

依据用户2026-10-23最新反馈：爱音日常长时间保持轻微微笑，回复时根据明确语气切换表情。保留R19脸型、眼睛、发型、R16身体服装及R20嘴角尺度，不重新塑造角色。不移动眼距，不加脸颊方块，不改颜色，不新增夸张张嘴或露齿。

制作五个可编辑表情工程：轻微笑、开心、疑惑、认真、担心。仅调整已命名的嘴和四个眉毛长方体。开心稍抬眉、略加深嘴角；疑惑轻抬单侧眉、小矩形嘴；认真收平嘴角、眉尾少量调整；担心眉内端稍抬、嘴角轻下垂。所有变化保持有限幅度，使用原贴图、原立方体厚度、原头部父级。

源工程、运行网格及正面/斜侧预览同时输出。逐一查看实际网格渲染，检查嘴唇是否消失、眉毛是否穿头发、眼口是否协调、身体与头发是否完全保持。表情是有限规则，不宣称理解任意语义或音素口型。受伤/战斗/无电优先；默认微笑不会每四秒消失。实际语音播放期间保持相应表情，暂停或结束后恢复日常状态。
